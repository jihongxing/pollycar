# 真实账号与认证供应商测试计划

## 适用范围

本计划覆盖：

- 腾讯云短信 SMS；
- 腾讯云慧眼人脸核身；
- 阿里云应用身份服务 IDaaS EIAM。

当前没有企业账号、合同、托管测试凭据或真实数据批准，因此本文只固定测试入口、失败关闭规则和证据要求，不代表已完成供应商沙箱联调。

## 统一前置条件

开始任何供应商测试前必须同时满足：

1. 企业账号和隔离测试应用已创建；
2. 合同、数据处理和测试数据范围完成批准；
3. 凭据只通过托管 Secret Reference 提供；
4. 测试数据只使用供应商测试数据和不可对应真实个人的合成数据；
5. 日志、监控和审计已验证不会保存敏感原文；
6. 测试结束后具备凭据吊销和测试数据删除方法。

## 腾讯云短信 SMS

### 请求与幂等

- PollyCar 为每个验证码挑战生成唯一内部幂等键。
- 同一挑战的客户端重试只返回原有发送状态，不创建第二次发送。
- 新验证码签发后旧挑战立即失效。
- 不根据同步 HTTP 超时自动重复发送短信。

### 未知结果恢复

- 同步调用超时、连接中断或返回状态不明确时，将挑战标记为 `delivery_unknown`。
- 优先使用供应商状态查询或回执确认最终结果。
- 状态仍未知时不自动重发，由用户在冷却时间后发起新的挑战。

### 回调验证

- 回调只允许 HTTPS。
- 验证腾讯云签名或产品文档定义的等价真实性机制。
- 校验请求标识、手机号摘要、模板、发送时间窗口和内部挑战绑定。
- 重复回调必须幂等；不匹配、过期或无法验证的回调拒绝并记录安全审计。

### 限流

- 同一手机号六十秒最多一次、一小时最多五次、二十四小时最多十次。
- 同一设备一小时最多十次、二十四小时最多二十次。
- 同时设置租户用量阈值、费用告警和停发熔断。
- 供应商限流不能替代 PollyCar 服务端限流。

### 验收证据

- 企业账号与签名、模板审批截图或受控记录；
- 使用合成号码或供应商测试能力完成的成功、失败、超时和未知结果记录；
- 重复请求不重复发送的证据；
- 回调签名错误和重放被拒绝的证据；
- 频率限制和预算熔断证据；
- 测试凭据吊销和测试日志删除证明。

## 腾讯云慧眼人脸核身

### 请求与幂等

- 每次成年资格验证创建唯一会话和幂等键。
- 重复创建请求返回原会话，不创建第二套真实核验流程。
- 供应商请求必须绑定账户、设备、登录会话、告知授权版本和策略版本。

### 未知结果恢复

- SDK 退出、网络超时、服务端超时或回调缺失时，结果保持 `unknown` 或 `pending_provider_result`。
- 优先查询供应商最终状态，不得把客户端“完成”视为通过。
- 查询仍无明确结论时保持业务能力关闭，并允许安全重试或人工申诉。

### 回调验证

- 验证 HTTPS、供应商签名、时间窗口、请求编号和内部会话绑定。
- 只接受预期状态转换；重复结果幂等。
- 签名错误、会话不匹配、过期、未知枚举或缺少必要检查结果时拒绝通过。

### 限流

- 限制账户、设备、登录会话和网络来源的创建频率。
- 同一失败原因的自动重试必须退避。
- 设置每日调用量、费用告警和异常攻击熔断。

### 数据边界

- 优先使用供应商直传或 SDK 通道。
- PollyCar 业务 API、数据库、日志和审计不得保存原始证件、人脸、活体视频、生物特征模板或完整供应商令牌。
- PollyCar 只接收最小验证结论、请求摘要、必要字段、策略版本和审计关联。

### 验收证据

- 企业申请和隔离测试应用记录；
- 合成或供应商测试数据下的成功、失败、未知、超时和人工复核记录；
- 回调签名错误、重放和会话不匹配被拒绝的证据；
- 原始材料未进入 PollyCar 日志、数据库和业务 API 的扫描证据；
- 供应商侧测试数据删除和凭据吊销证明。

## 阿里云 IDaaS EIAM

### OIDC 流程

- 使用 Authorization Code Flow，并在供应商能力允许时启用 PKCE。
- 固定并校验 Issuer、Client ID、Audience、回调地址、State、Nonce 和签名算法。
- 不允许通过邮箱或身份源组声明直接获得 PollyCar 业务权限。
- 登录成功后由 Server 查询内部工作身份、组织范围和业务能力。

### 幂等与未知结果

- 同一授权回调只能消费一次。
- 重复回调返回相同安全结果，不重复创建活动会话。
- 身份源超时、令牌交换未知、用户同步失败或声明缺失时拒绝创建业务会话。
- 刷新令牌重放、账号离职、成员关系撤销或角色变化必须撤销相关会话。

### MFA 与恢复

- 测试 WebAuthn/Passkey 或供应商提供的抗钓鱼 MFA。
- 仅在登记限时例外时允许 TOTP；短信 MFA 永久禁止。
- MFA 重置、紧急访问和账户恢复必须职责分离，并验证全部会话撤销。

### 限流

- 限制账号、网络来源、租户、回调失败和 MFA 重置频率。
- 连续五次失败锁定三十分钟，并保持账户枚举保护。
- 设置身份源不可用告警和受控紧急访问流程。

### 验收证据

- 企业租户、测试应用、Issuer、Client ID 和回调域名记录；
- OIDC State、Nonce、签名、Audience 和重放专项测试；
- MFA、离职同步、组映射、会话撤销和审计导出测试；
- 身份源不可用、回调错误和令牌刷新失败恢复演练；
- 测试应用、Client Secret 或私钥吊销证明。

## 证据回填规则

- 只有三类供应商都完成上述沙箱测试后，才能填写 `supplierSandboxTestEvidenceReference`。
- 单一供应商测试完成时，应分别保存受控证据，但总门禁继续保持阻断。
- 内部单元测试、合成 Adapter 测试和官方产品文档不能替代真实供应商测试证据。
