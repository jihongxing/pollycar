# 共享预生产基础设施落地说明

## 当前状态

当前仅完成供应商中立设计，禁止创建共享云资源、部署服务、接入真实数据或启用业务能力。机器事实源为 `spec/platform/shared-preproduction.yaml`，审批决策为 `docs/decisions/0029-共享预生产基础设施设计与审批.md`。

## 未来基础设施即代码边界

后续 IaC 必须拆分为以下独立层，并由不同权限执行：

1. 组织与账号层：独立账号、预算、审计汇聚、状态存储和执行身份。
2. 网络与安全层：虚拟网络、跨可用区子网、路由、WAF、受控入口、出站允许列表、私有服务端点和流日志。
3. 数据层：托管 PostgreSQL、加密密钥、参数组、备份策略、时间点恢复和数据库访问安全组。
4. 身份与密钥层：工作负载身份、托管密钥、证书、轮换、紧急访问和审计。
5. 计算与入口层：仅健康检查的 Server、托管负载均衡、证书绑定和默认关闭业务路由。
6. 可观测性层：OTLP、日志、指标、追踪、告警、归档、访问审计和保留删除策略。
7. 灾备层：独立恢复目标、恢复演练、可用区切换和区域重建验证。

## 当前可执行的只读计划

仓库现在提供供应商中立的 IaC 输入契约与只读计划工具：

```powershell
pnpm infra:shared-preproduction:plan
pnpm check:shared-preproduction:iac
```

- 输入模板为 `iac-input.example.json`，JSON Schema 为 `iac-input.schema.json`；模板中的 `null`、空数组和未批准状态是当前真实状态，不得用虚构值替代。
- `plan` 只会输出阻断项、输入摘要、架构层级和空的资源变更列表；当前结果必须为 `blocked`，且资源变更必须为 `0`。
- `apply` 命令存在仅用于验证失败关闭。它要求机器事实源、五类批准、输入摘要确认和不可变证据全部生效；即使未来满足这些条件，在供应商适配器经过独立评审前也不会创建资源。
- 输入不得包含口令、私钥、访问密钥、API Key、Token 或任何原始密钥值；只能填写托管密钥服务和受控引用。

## 创建资源前的输入

以下内容必须由外部责任人提供并完成签署，不得由代码默认推断：

- 云供应商、合同主体、账号或订阅、计费币种和月度预算上限；
- 主区域、可用区、数据驻留结论和跨地域限制；
- 托管 PostgreSQL 产品、版本、规格、存储、连接上限和维护窗口；
- 公开或内部域名、DNS 托管方、证书服务和私有 CA 方案；
- 托管密钥与加密密钥服务、轮换责任、紧急访问审批人；
- VPN、身份感知代理、测试出口、值班与运维访问角色；
- 监控供应商、存储区域、字段清单、保留期、容量和预算；
- `RPO 5 分钟`、`RTO 60 分钟` 的业务接受人及演练窗口；
- 五类批准证据的不可变引用。

## 推荐落地顺序

1. 完成威胁模型、数据流、成本估算和供应商评审。
2. 创建独立账号与加密的远程 IaC 状态存储。
3. 部署网络、审计汇聚、密钥和监控存储。
4. 部署无公网端点的托管 PostgreSQL，并验证 TLS 与时间点恢复。
5. 签发托管证书，建立工作负载身份和最小权限密钥读取。
6. 部署仅健康检查可达的生产就绪 Server。
7. 执行迁移、健康检查、备份恢复、可用区故障切换和区域重建演练。
8. 汇总资源清单、成本、配置差异、演练结果和审批证据。

## 失败关闭条件

发生以下任一情况时，不得执行资源创建或部署：

- 任一批准状态不是已批准，或证据引用缺失、过期、撤销；
- 供应商、账号、区域、域名或预算仍未确定；
- 数据库存在公网端点，或应用、数据库拥有公网地址；
- 使用自签名证书、长期云访问密钥、仓库密钥或镜像内密钥；
- 监控允许采集请求体、凭据、身份材料、生物特征、精确位置或支付数据；
- 时间点恢复、独立恢复库、健康检查或访问控制验证未通过；
- 任一真实业务能力、真实数据或生产启用开关不为关闭状态。
- 只读计划出现非零资源变更，或 `apply` 未因缺失门禁失败。
