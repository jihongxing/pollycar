# 核心出行全量交付矩阵

## 目标

本矩阵用于推进 `docs/product/06-核心出行功能清单.md` 的全部文字要求。

唯一排除项为真实支付能力。真实支付、真实扣款、真实分账、真实结算和真实提现不得启用。

其他能力采用以下交付口径：

- 完成生产级领域模型、公开契约、应用服务、App 交互、权限、安全、数据生命周期和自动化验收。
- 涉及真实位置、真实聊天、真实通知、真实身份材料或外部服务时，完成可替换适配器和默认关闭门禁。
- 没有外部凭证、法律结论、运营批准或实体设备时，不伪造真实启用或真实验收结果。
- `production_enabled: false` 在单独获得生产启用批准前持续生效。

## 持续门禁

```yaml
production_enabled: false
real_payment: false
paid_flex_trial: false
real_user_invitation: false
shanghai_pilot: false
real_data_ingestion: false
```

真实位置、聊天、身份材料和通知适配器可以完成生产级实现，但在批准前必须拒绝真实数据写入，并使用合成数据完成验收。
