| R02 | 目的地搜索 | 默认叫车 | 搜索和复用地点 |
| R03 | 行程确认 | 默认叫车 | 确认起终点、人数和场景 |
| R04 | 等待接单 | 默认叫车 | 等待车主自主接单 |
| R05 | 车主接驾 | 默认叫车 | 识别车主和车辆并联系 |
| R06 | 接单后取消 | 默认叫车 | 3 分钟内主动取消 |
| R07 | 行程进行中 | 默认叫车 | 查看进度、联系和安全处理 |
| R08 | 行程完成 | 默认叫车 | 查看结果和再次叫车 |
| D01 | 车主离线首页 | 车主工作模式 | 上线开始接单 |

## 页面登记要求

每个进入实现的页面必须补齐：

- 路由和入口；
- 当前身份要求；
- 页面数据；
- 允许操作；
- 应用命令；
- 成功事件；
- 错误码；
- 加载、空、关闭、冻结和并发状态；
- 权限与审计；
- 验收场景。
