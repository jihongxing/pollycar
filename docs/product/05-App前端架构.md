# App 前端架构

## 技术基线

App 技术选型以 `docs/decisions/0008-App前端技术选型.md` 为准：

- React Native；
- Expo；
- Expo Router；
- TypeScript 严格模式；
- TanStack Query；
- React Hook Form；
- React Native Testing Library。

视觉与交互以根目录 `DESIGN.md` 为唯一真相源。

## 分层

```text
路由层
  ↓
页面与功能层
  ↓
应用编排层
  ↓
公开契约与基础设施层
```

### 路由层

- 定义共享、乘客和车主路由组；
- 执行身份上下文守卫；
- 处理深链接、返回和关闭状态；
- 不包含业务规则和网络请求细节。

### 页面与功能层

- 按车辆审核、资格、行程、安全等功能组织；
- 页面只组合可复用组件并触发应用意图；
- 每个页面覆盖加载、空、错误、关闭、冻结和并发状态；
- 不直接读取其他身份的数据缓存。

### 应用编排层

- 执行身份切换；
- 编排查询失效、表单提交和错误映射；
- 把机器错误码翻译为可行动界面状态；
- 不复制 Server 的资格、配额、审核或权限判断。

### 公开契约与基础设施层

- API 客户端只依赖 `packages/contracts`；
- 统一注入请求关联 ID、当前账户和当前身份声明；
- 统一处理超时、取消、重试和日志脱敏；
- 内部沙箱使用内存或合成 API 适配器，不连接真实供应商。

## 身份上下文

身份上下文至少包含：

```ts
type IdentityContext = {
  accountId: string;
  activeIdentity: "passenger" | "owner";
  availableIdentities: readonly IdentitySummary[];
  sandbox: true;
};
```

它不包含：

- 权限最终结论；
- 资格最终结论；
- 配额数字的客户端推导；
- 身份原件；
- 支付、位置或聊天敏感原文。

服务端必须对每个命令重新鉴权，客户端身份上下文只是请求意图和界面导航依据。

## 查询与缓存

- 查询键必须包含账户、身份上下文和资源标识；
- 身份切换后取消上一身份进行中的非共享请求；
- 清理上一身份的页面级敏感缓存；
- 共享账户数据与身份数据使用不同查询键空间；
- 审核、支付和安全状态默认以服务端刷新结果为准；
- 只有明确幂等的读取失败允许自动重试。

## 表单

- React Hook Form 管理页面级表单；
- 草稿默认保存在内存；
- 切换身份、退出流程或应用进入后台时按敏感等级决定丢弃；
- 服务端字段错误映射到具体字段；
- 业务拒绝显示为页面级状态，不伪装成字段格式错误；
- 合成附件使用预置引用，不允许选择真实相册或文件。

## 错误处理

- 使用 `spec/api/error-codes.yaml` 的机器错误码；
- 页面不解析错误文案；
- `401/403` 不自动切换身份或重放写命令；
- 并发冲突重新获取最新状态并要求用户确认；
- 功能关闭展示 `StatusBanner` 与允许的替代行动；
- 未知错误记录关联 ID，但不上传敏感上下文。

## 组件边界

基础组件：

- 主题与排版；
- 按钮、输入、卡片、标签；
- 状态横幅、时间线、原因列表；
- 身份徽标和身份切换面板；
- 页面骨架、空状态和错误状态。

功能组件：

- 车辆资料表单；
- 审核进度；
- 补充材料任务；
- 资格与配额摘要；
- 行程状态和责任提示。

功能组件可以依赖基础组件，基础组件不得依赖具体领域功能。

## 测试策略

- 令牌与纯函数：Vitest；
- 基础组件：React Native Testing Library；
- 页面：以合成查询和命令适配器测试所有状态；
- 身份切换：测试缓存隔离、未提交表单、禁止切换和深链接；
- 首个切片：覆盖申请、补充、拒绝、批准、并发和关闭状态；
- 端到端测试框架在应用可运行后另行决定。

## 安全与隐私

- 不把令牌、身份原件或敏感材料写入普通持久化存储；
- 不在日志记录表单原文、附件内容、位置和支付数据；
- 开发菜单不能绕过 feature gates；
- 截图、错误上报和调试工具接入前必须经过数据分类评审；
- 沙箱构建必须持续显示内部沙箱标识。

2. 建立共享外壳与身份上下文；
3. 实现身份切换器；
4. 实现车主申请说明、车辆资料和提交确认；
5. 实现审核进度、补充材料和审核结果；
6. 实现车主工作台关闭态；
7. 补齐页面状态测试和可访问性测试。
