# 产品功能地图

## 单一用户 App

### 账户与工作模式

- 合成身份登录；
- 账户安全状态；
- 车主身份申请与状态；
- 默认进入叫车首页，不显示乘客身份；
- 主动进入和退出车主工作模式；
- 沙箱状态与真实能力关闭说明。

### 默认叫车与行程

- 地图、当前位置和上车点；
- 目的地搜索、常用地点和最近搜索；
- 行程创建；
- 可选乘车场景；
- 必选乘车人数，默认 1 人、最多 3 人；
- 固定价格确认；
- 支付前置状态；
- 等待车主自主接单；
- 车主头像、性别图标和车辆识别信息；
- 接单后 3 分钟内主动取消，取消原因非强制；
- 接驾、行中和完成页面；
- 取消、退款和争议；
- 双向确认与临时对话；
- 举报和申诉。

### 车主工作模式

- 车主准入；
- 车辆资料与审核；
- 单次最大乘客人数，默认 1 人、最多 3 人；
- 资格和配额；
- 可接订单；
- 乘车人头像和自愿公开的性别图标；
- 车主逐单自主接受或忽略，平台不强制派单、不自动接单；
- 接驾、等待上车、履约和滑动到达；
- 车主订单列表和详情；
- 资金中心、银行卡和提现关闭态；
- 免费弹性资格；
- 取消责任和申诉；
- 举报和安全处置。

### 共享能力

- 行程临时会话；
- 通知中心；
- 任务提醒；
- 帮助与规则说明；
- 隐私和数据权利；
- 安全中心；
- 账户设置。

## 内部运营后台

### 审核工作台

- 乘客审核；
- 车主审核；
- 车辆审核；
- 补充材料；
- 复核与升级；
- 免费弹性资格审核。

### 履约与责任

- 行程查询；
- 取消责任判定；
- 零金额责任记录；
- 退款状态查看；
- 异常任务处理。

### 安全工作台

- 举报受理；
- 风险冻结；
- 证据访问；
- 调查记录；
- 申诉与恢复；
- 数据保留和删除任务。

### 运营与平台

- 城市和服务区域；
- 营业时段；
- 价格与容量只读预览；
- 功能门禁；
- 沙箱主体和合成数据；
- 审计、任务、健康和可观测性。

## 当前实现优先级

1. 将已批准的核心出行功能清单转化为详细交互和组件规格。
2. 重构默认叫车首页、目的地搜索和行程确认。
3. 重构车主工作模式、订单卡和自主接单。
4. 补齐接驾识别、3 分钟取消、上车确认和滑动到达。
5. 补齐订单、资金中心、绑卡和提现关闭态。
6. 重构临时会话、消息中心和我的。

真实支付、真实邀请、真实位置、真实聊天和上海试点只允许完成关闭状态与接口边界，不得启用。
