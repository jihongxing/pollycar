# 产品切片 0001：车辆准入闭环

## 状态

`App 与 Server 合成闭环已完成，运营后台待实现`

## 用户结果

合成用户可以在单一 App 中申请车主身份、提交合成车辆资料、经历审核，并在审核通过后显式切换到车主身份工作台。

## 实现范围

App：

- 单账户身份上下文；
- 身份切换器；
- 车主身份申请；
- 合成车辆资料；
- 审核进度、补充材料和结果；
- 内部沙箱与真实能力关闭状态。

Server：

- 车主身份与车辆审核应用服务；
- 车辆审核状态持久化端口；
- 审核任务编排；
- 幂等、乐观并发和错误映射；
- 审计、日志、指标和追踪。

运营后台：

- 审核队列；
- 任务认领；
- 批准、拒绝、补充和升级；
- 审计与任务状态查看。

测试：

- 应用服务单元测试；
- 端口契约测试；
- App 页面状态测试；
- 正常、拒绝、补充、升级、并发和审计场景；
- 合成端到端闭环。

## 不在范围

- 真实登录和身份供应商；
- 真实证件或车辆原件上传；
- 真实数据库写入；
- 真实通知；
- 真实接单；
- 真实支付；
- 上海试点启用。

## 实施顺序

1. 建立身份上下文和车辆审核应用契约。
2. 实现 Server 车辆审核应用服务。
3. 实现审核任务和内存持久化。
4. 实现用户 App 申请与状态页面。
5. 实现运营后台审核页面。
6. 建立页面到命令、事件和错误映射。
7. 完成合成端到端验收。

## 完成标准

- 用户 App 保持单一应用形态。
- 同一账户可安全持有并切换乘客、车主身份。
- 身份切换不能绕过车主和车辆准入。
- 完整审核分支可在合成数据下运行。
- 页面状态、Server 规则和审计结果一致。
- 所有真实能力继续默认关闭。
- 完整预检和切片验收测试通过。
