## 阶段范围

阶段三只包含：

- 行程运营中心和异常任务；
- 行程 360° 只读聚合；
- 预约、匹配、接驾、进行中和结束异常协调；
- 统一客服案件、申诉和升级；
- 安全案件最小详情、调查任务和独立恢复复核；
- 跨主体隔离协作任务；
- 字段级限时证据访问；
- 应急响应状态和未知结果恢复任务。

不包含：

- 通用行程状态编辑器；
- 真实客服、真实安全证据或真实应急联动；
- 客服直接退款、核销资金差异或决定安全结论；
- 安全人员修改客服、审核或资金结论；
- 阶段四资金操作；
- 生产启用。

## 行程运营

行程状态继续使用既有十三个权威状态。后台不拥有第二套行程状态，只拥有运营任务：

```text
已检测
→ 已分诊
→ 协调中
→ 等待权威结果
→ 已解决
→ 已关闭
```

允许的后台动作只能是：

- 认领异常任务；
- 添加结构化分诊分类；
- 请求既有领域命令；
- 创建本主体或跨主体协作任务；
- 关联客服或安全案件；
- 查询原命令结果；
- 记录权威结果并关闭运营任务。

不得提供自由选择目标行程状态、直接更新数据库、重放旧回调或在未知结果时重新提交。

## 客服案件

固定状态：

```text
待处理
→ 已分配
→ 调查中
→ 等待用户／等待内部
→ 已升级
→ 已解决
→ 已关闭
↘ 重新打开
```

固定类别：

- 行程服务；
- 预约与改期；
- 取消；
- 沟通；
- 运营主体协作；
- 资格；
- 安全转介；
- 资金转介。

客服只能形成客服结论、沟通动作和升级任务。退款、冲正、资格恢复、安全恢复和行程状态变化必须由对应领域执行。

## 安全案件与应急响应

安全案件权威状态继续使用：

```text
冻结中／申诉中／已恢复／维持冻结
```

安全调查任务固定为：

```text
未分配 → 已分配 → 调查中 → 待独立复核 → 已完成
```

严重度固定为 `sev4`、`sev3`、`sev2`、`sev1`。`sev1` 和 `sev2` 必须展示应急响应、证据保全、资格同步和未关闭阻断状态。

冻结经办人不得独立批准恢复。严重案件恢复必须由不同安全负责人完成，并确认：

- 应急响应已关闭；
- 证据保全已确认；
- 资格同步已确认；
- 不存在未关闭阻断。

## 跨主体可见性

1. 运营主体范围以行程运营主体快照为准，后续主运营关系迁移不改写历史行程。
2. 平台只能查看当前服务端授权主体范围。
3. 运营主体只能查看本主体行程和分配给本主体的协作任务。
4. 跨主体案件只创建一个平台案件，各主体收到隔离任务。
5. 运营主体不能看到另一主体的内部备注、员工身份、联系方式、聊天原文、完整轨迹或安全推理。
6. 运营主体安全协作页面只展示动作、期限、状态和最小必要摘要。
7. 深链接、导出和 API 必须重新执行同一范围校验。

## 证据访问

默认只展示遮蔽摘要。原文访问必须包含：

- 案件编号；
- 工单编号；
- 目的码；
- 精确字段；
- 申请人；
- 审批人；
- 到期时间；
- 访问审计提示。

普通访问最长三十分钟；紧急破窗最长十五分钟。聊天原文、完整位置轨迹和导出必须双人批准。到期、切换角色、组织、案件或成员关系后立即重新遮蔽。

客服不能申请安全证据包；运营主体不能申请聊天原文和完整位置轨迹；技术运维不能凭技术职责读取业务证据。

## 未知结果恢复

写命令结果固定为：

```text
已受理／成功／失败／未知
```

恢复任务固定为：

```text
待处理
→ 查询幂等结果
→ 对照权威状态
→ 等待 Outbox 确认
→ 恢复为成功／恢复为失败
↘ 已升级
```

未知结果期间同资源同动作保持冻结。恢复只能查询原幂等键和请求摘要，不得创建替代请求。技术运维只能确认技术事实，业务结论仍由原业务角色完成。

## 并发、审计与恢复

- 所有写命令必须携带幂等键、请求摘要、资源版本、理由码和关联标识。
- 案件认领使用租约，过期后自动释放。
- 允许、拒绝、披露、导出、升级、复核、恢复和未知结果查询全部追加审计。
- 审计不得记录聊天原文、完整轨迹或严格敏感字段。
- 资源版本冲突必须刷新，不允许覆盖提交。
