# 阶段五高层驾驶舱契约

## 冻结结论

`阶段五角色、组织范围、指标口径、数据新鲜度、关账标识、钻取、受控导出、审计和六页范围已冻结；尚未批准代码实现`

唯一机器契约：

- `spec/admin/executive-dashboard.yaml`
- `spec/tests/admin-executive-dashboard-scenarios.yaml`
- `spec/security/roles.yaml`
- `spec/security/authorization-rules.yaml`
- `spec/api/error-codes.yaml`
- `spec/platform/feature-gates.yaml`

## 依赖与门禁

阶段五仅在以下默认关闭门禁的合成能力均可用时进入未来实现：

```text
internal_sandbox
+ synthetic_admin_multi_organization
+ synthetic_admin_operator_management
+ synthetic_admin_trip_operations
+ synthetic_admin_case_management
+ synthetic_admin_finance_operations
+ synthetic_admin_executive_dashboard
```

设计通过不等于允许打开门禁。

## 角色与边界

| 角色 | 组织范围 | 允许 | 禁止 |
| --- | --- | --- | --- |
| 项目决策人 `executive_sponsor` | 平台授权城市与主体 | 跨领域聚合、重大风险、待决事项 | 经办、复核、恢复、配置发布 |
| 运营负责人 `operations_lead` | 平台运营范围 | 经营趋势、城市和主体健康 | 资金决定、安全恢复 |
| 财务负责人 `finance_lead` | 平台财务范围 | 资金安全和已关账经营指标 | 从驾驶舱发起资金命令 |
| 安全负责人 `safety_lead` | 平台安全范围 | 安全趋势和重大案件摘要 | 从驾驶舱查看证据原文 |
| 隐私合规 `privacy_compliance` | 平台治理范围 | 隐私、权限异常和导出复核 | 常规经营经办 |
| 运营主体负责人 `operator_executive` | 固定单一主体 | 本主体经营、资金和风险聚合 | 跨主体、个人明细和平台总量 |

高层角色不继承阶段二至阶段四的写权限。高层职级不能绕过职责分离。

项目决策人与运营主体负责人可以追加记录高层决策意见，但意见只构成治理输入，不执行原领域动作，不改变待决事项对应资源状态。

## 指标治理

每个指标必须登记：

- 稳定指标标识与版本；
- 中文名称和业务定义；
- 分子、分母或聚合公式；
- 时间范围与 `Asia/Shanghai` 时区；
- 权威数据来源；
- 是否要求关账；
- 新鲜度目标和当前截至时间；
- 允许维度；
- 禁止解释；
- 数据等级和最小样本规则。

核心指标固定为：

1. 行程完成率；
2. 接单率；
3. 取消率；
4. 付款及时率；
5. 对账差异率；
6. 关账完成率；
7. 主体健康度；
8. 安全事件率。

客户端不得重新计算比率、金额或健康等级。

所有页面实际展示的计数、金额、时长和阻断数也必须登记为指标，不得只登记八项核心比率。

统一计算规则：

- 比率分母为零时返回 `not_applicable`，不得返回 `0%`；
- 比率由 Server 返回万分比整数，页面最多展示一位小数；
- 金额使用十进制最小货币单位字符串，页面只负责格式化；
- 时长使用整数秒，页面只负责单位转换；
- 组合指标的截至时间取所有组成来源中最早的时间；
- 迟到事件和历史修正生成新快照，不覆盖已发布快照。

主体健康度固定采用最严重维度优先规则：

1. 任一资金、安全或合规硬阻断存在时为 `blocked`；
2. 无硬阻断且任一维度为关注时为 `attention`；
3. 四个维度均正常时为 `healthy`；
4. 任一必需来源不可用时为 `unavailable`，不得使用剩余维度推导健康；
5. 每次结果必须返回规则版本、四维结果和触发原因。

## 时间与关账

- 实时运营指标目标延迟不超过 `5 分钟`；
- 客服和安全案件目标延迟不超过 `1 分钟`；
- 资金状态以权威事务提交时间为准；
- 周报和月报只使用已关闭期间；
- 页面必须显示数据截至时间、来源状态和是否包含未关账数据；
- 新鲜度超限时保留最后可信值并醒目标识，不得伪装为实时。
- 单一来源失败时只降级受影响卡片；正式周报、月报和任何导出必须失败关闭。

## 钻取与披露

- 一级钻取仅允许城市、运营主体、产品和时间；
- 人员、行程、案件、付款和账本明细必须跳转原领域并重新授权；
- 驾驶舱不得返回完整手机号、银行卡、支付凭据、证件、聊天正文或精确位置；
- 小样本、单一人员或可合理重识别的切片必须抑制；
- 筛选参数不能扩大服务端会话范围。

## 待决事项

只展示需要高层判断的事项：

- 运营主体激活、暂停或退出；
- 重大安全事件处置；
- 长期付款逾期；
- 无法闭环的资金差异；
- 生产能力启用评审；
- 法律、财务和合规未决事项。

驾驶舱只能显示摘要、责任角色、截止时间和原工作台链接。任何批准、拒绝、付款、退款、冻结、恢复或关账仍在原职责工作台执行。

高层决策意见采用追加式记录：

- 必须引用一项开放待决事项；
- 必须包含 `decision_code`、`reason_code`、责任角色和截止时间；
- 不接受自由文本敏感原文；
- 不允许修改或删除，只能创建带 `supersedes_opinion_id` 的替代意见；
- 记录成功后待决事项仍保持原状态。

## 受控导出

阶段五治理写入口固定为：

```text
POST /v1/internal-sandbox/admin/executive-dashboard/decision-opinions
POST /v1/internal-sandbox/admin/executive-dashboard/export-requests
POST /v1/internal-sandbox/admin/executive-dashboard/export-requests/{export_request_id}/privacy-decision
POST /v1/internal-sandbox/admin/executive-dashboard/export-requests/{export_request_id}/domain-decision
POST /v1/internal-sandbox/admin/executive-dashboard/export-requests/{export_request_id}/revocation
GET  /v1/internal-sandbox/admin/executive-dashboard/export-requests/{export_request_id}/download
```

这些入口只写治理记录，不写业务状态。所有写请求必须具备幂等键、请求摘要、理由码和资源版本。

导出状态固定为：

```text
draft
→ awaiting_privacy_review
→ awaiting_domain_review
→ approved
→ downloaded
```

任一审批可进入 `rejected`；批准后可进入 `revoked` 或 `expired`。已下载、已拒绝、已撤销和已过期均为终态。

单次导出仅允许一个职责域：

- 经营：`privacy_compliance` 与 `operations_lead`；
- 资金：`privacy_compliance` 与 `finance_lead`；
- 安全合规：`privacy_compliance` 与 `safety_lead`。

运营主体负责人申请时同样由平台双人批准。两名批准人均不得是申请人。导出文件必须加密存储，批准后最多保留 `30 分钟`，下载后立即失效，未下载文件到期自动删除。

## 查询 API

阶段五查询路径固定为：

```text
GET /v1/internal-sandbox/admin/executive-dashboard/overview
GET /v1/internal-sandbox/admin/executive-dashboard/operations-health
GET /v1/internal-sandbox/admin/executive-dashboard/operator-health
GET /v1/internal-sandbox/admin/executive-dashboard/finance-safety
GET /v1/internal-sandbox/admin/executive-dashboard/safety-compliance
GET /v1/internal-sandbox/admin/executive-dashboard/decision-items
GET /v1/internal-sandbox/admin/executive-dashboard/metrics
GET /v1/internal-sandbox/admin/executive-dashboard/drilldowns/{dimension}/{dimension_id}
```

所有查询必须从服务端会话取得范围，不接受可扩大范围的组织参数。

## 聚合读取架构

阶段五只允许一个 `ExecutiveDashboardQueryService` 组合领域指标适配器：

- `OperatorExecutiveMetricsPort`；
- `TripExecutiveMetricsPort`；
- `DispatchExecutiveMetricsPort`；
- `SupportExecutiveMetricsPort`；
- `SafetyExecutiveMetricsPort`；
- `FinanceExecutiveMetricsPort`。

适配器只返回去标识、按组织范围过滤的指标事实，不调用阶段二至阶段四的 HTTP 路由，也不复用面向经办任务的授权结果。

指标快照唯一键固定包含：

```text
metric_id
+ metric_version
+ window_start
+ window_end
+ dimension_key
+ organization_scope_digest
+ as_of
```

同一快照不可更新；迟到修正必须写入新 `as_of` 快照。

## 资金数据等级

- 项目决策人和运营主体负责人只读取 `L2` 的状态、区间和趋势；
- 财务负责人通过独立 `L3` 授权读取精确聚合金额；
- 页面和导出不得通过格式化、筛选或钻取把 `L3` 精确金额降级披露。

## 页面状态矩阵

每页必须固定处理：

- `ready`：全部来源可用；
- `partial`：部分非关键卡片不可用；
- `stale`：超过新鲜度目标并显示原截至时间；
- `unclosed`：包含未关账资金；
- `suppressed`：小样本或可重识别切片被抑制；
- `unavailable`：关键来源不可用；
- `scope_denied`：服务端拒绝范围；
- `feature_disabled`：阶段五门禁关闭。

正式报告和导出仅允许 `ready` 且要求关账的数据已关闭时执行。

## 固定页面

1. 高层总览；
2. 经营趋势与城市健康；
3. 运营主体健康；
4. 资金安全；
5. 安全与合规；
6. 待决事项与指标口径。

六页必须覆盖默认关闭、范围越权、数据陈旧、未关账标识、小样本抑制、字段披露、钻取重授权、导出职责冲突和移动端无页面级横向溢出。

## 当前准入

2026 年 7 月 14 日已正式批准在默认关闭的 `synthetic_admin_executive_dashboard` 门禁后进入合成代码实现。

允许：

- 新增阶段五内部沙箱运行时、HTTP API、Admin 模块和专项测试；
- 使用去标识、服务端范围过滤的合成指标适配器；
- 写入追加式高层意见、导出申请、双人审批、撤销和单次下载治理记录；
- 运行目标测试、类型检查、构建、浏览器验收和完整治理检查。

禁止：

- 将 `synthetic_admin_executive_dashboard` 默认开启；
- 接入真实经营、真实财务、真实安全或真实人员数据；
- 将高层角色添加到阶段二至阶段四写动作；
- 从驾驶舱执行批准、拒绝、付款、退款、冻结、恢复、关账或生产启用；
- 启用生产环境。
