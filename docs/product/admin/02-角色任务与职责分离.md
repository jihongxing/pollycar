# 运营控制台角色、组织范围与职责分离

## 授权模型

后台授权不再只使用单个角色名称，而采用以下组合：

```text
允许操作
= 功能角色
× 所属组织
× 城市范围
× 资源范围
× 资源状态
× 操作目的
× 数据等级
× 临时授权
× 职责分离
```

每个内部身份至少包含：

```text
internal_user_id
organization_type
organization_id
functional_roles
city_scopes
operator_scopes
maximum_data_classification
temporary_grants
session_assurance
```

## 组织类型

| 组织类型 | 数据范围 | 主要职责 |
| --- | --- | --- |
| 平台 | 获批城市和运营主体 | 规则、治理、监督、复核、跨主体异常和平台经营 |
| 运营主体 | 本主体和授权城市 | 运力、行程协作、客服、车主付款和主体内部运营 |
| 项目治理 | 聚合只读范围 | 战略、经营、资金安全、合规和重大风险决策 |

## 平台功能角色

| 角色 | 核心任务 | 禁止事项 |
| --- | --- | --- |
| 平台运营专员 | 城市运行、异常行程、运营任务 | 修改资金和安全结论 |
| 平台运营负责人 | 跨主体协调、限制和恢复复核 | 复核自己的原操作 |
| 运营主体管理员 | 入驻、能力、迁移和退出 | 处理主体内部付款 |
| 审核员 | 标准车主和车辆审核 | 安全调查、资金操作 |
| 高级审核员 | 升级和独立复核 | 自我复核 |
| 客服专员 | 咨询、投诉、取消和退款案件 | 查看无关安全证据 |
| 客服负责人 | 高风险投诉和补偿复核 | 修改账本金额 |
| 安全人员 | 安全调查、冻结和证据保全 | 代替普通审核或财务决定 |
| 安全负责人 | 重大事件、恢复和复盘 | 自我复核 |
| 财务经办人 | 对账、清算和付款准备 | 批准本人准备的批次 |
| 财务复核人 | 差异解决、付款和关账复核 | 修改权威金额 |
| 风险合规人员 | 规则命中、限制、合规任务 | 直接执行资金付款 |
| 隐私合规人员 | 数据请求和披露审查 | 普通业务决定 |
| 审计人员 | 只读检查控制和证据 | 业务写操作 |
| 技术运维 | 任务、死信和受控重放 | 审核、付款和安全结论 |

## 运营主体功能角色

| 角色 | 本主体任务 | 主要限制 |
| --- | --- | --- |
| 主体负责人 | 主体健康、重大风险和待决事项 | 默认不查看严格敏感原文 |
| 运营主管 | 运力、行程、逾期和服务质量 | 不能批准付款 |
| 运力专员 | 车主、车辆、主运营关系和证照 | 不能跨主体查询 |
| 车主服务人员 | 车主咨询、资料协作和付款状态解释 | 不能修改应付款 |
| 客服人员 | 本主体关联行程和服务案件 | 不能查看平台全量用户 |
| 财务经办人 | 清算和车主付款准备 | 不能复核自己的批次 |
| 财务复核人 | 独立复核和提交确认 | 不能修改系统计算金额 |
| 安全联络人 | 接收本主体安全协作任务 | 不能查看无关案件证据 |
| 主体审计人员 | 本主体只读审计 | 不能执行写操作 |

## 项目高层角色

| 角色 | 默认视图 | 写权限 |
| --- | --- | --- |
| 项目负责人 | 全局经营、重大风险和待决事项 | 无业务写权限 |
| 运营负责人 | 城市和主体健康、运力与服务 | 仅批准明确治理事项 |
| 财务负责人 | 资金安全、对账、关账和付款时效 | 仅独立高风险复核 |
| 安全合规负责人 | 重大安全、隐私和合规阻断 | 仅独立高风险复核 |
| 城市负责人 | 授权城市经营和风险 | 不跨城市 |
| 观察角色 | 延迟、脱敏的聚合指标 | 无 |

高层身份不能与日常经办身份合并使用。同一人员若承担两个职责，必须使用独立授权、独立会话目的和完整审计。

## 职责分离矩阵

| 动作 | 经办 | 复核 | 审计 | 技术运维 |
| --- | --- | --- | --- | --- |
| 车辆普通审核 | 审核员 | 高级审核员按需 | 只读 | 无 |
| 运营主体激活 | 主体管理员 | 运营负责人 | 只读 | 无 |
| 主运营关系迁移 | 运力专员 | 运营主管 | 只读 | 无 |
| 高风险安全恢复 | 安全人员 | 安全负责人 | 只读 | 无 |
| 对账差异解决 | 财务经办 | 财务复核 | 只读 | 无 |
| 清算批次完成 | 财务经办 | 财务复核 | 只读 | 无 |
| 车主付款提交 | 主体财务经办 | 主体财务复核 | 只读 | 无 |
| 账务日关闭 | 财务经办 | 财务复核 | 只读 | 无 |
| 死信重放 | 技术运维 | 技术运维复核 | 只读 | 执行 |
| 权限临时提升 | 权限管理员 | 安全或合规复核 | 只读 | 无 |

## 硬约束

- 用户不得处理本人、关联账户或所属利益主体的案件。
- 经办人与复核人必须是不同内部用户。
- 运营主体人员不得通过任何入口访问其他主体数据。
- 平台跨主体查看严格敏感字段必须绑定任务目的。
- 审计人员、观察角色和技术运维不得执行业务写操作。
- 不提供前端真实角色切换器。
- 临时权限必须有工单、目的、期限和到期自动撤销。
- 权限在确认期间失效时，操作必须中止。
- 退出组织、离职或角色撤销后，会话和待办所有权必须立即回收。

## 工作交接

- 任务转派记录原负责人、目标负责人、理由和时间。
- 升级后原经办人失去最终决定权限，只保留授权范围内跟踪。
- 运营主体任务升级平台后，主体人员只能查看可披露进展。
- 超时回收后，原人员不得继续提交旧版本操作。
- 未知结果任务不得新建替代命令，只能查询原命令结果。
