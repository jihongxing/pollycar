# 高层驾驶舱与指标口径

## 产品目标

高层驾驶舱帮助项目负责人、运营负责人、财务负责人和安全合规负责人理解经营健康、资金安全、重大风险和待决事项。

驾驶舱不是日常经办工作台，不提供直接付款、审核、冻结或状态修改能力。

## 首页结构

### 今日状态

- 当前环境和数据截止时间；
- 城市与运营主体运行状态；
- 今日订单、完成率和异常率；
- 当前可用运力；
- 重大安全和系统告警；
- 资金与关账状态。

### 经营趋势

- 订单量；
- 完成率；
- 即时与预约占比；
- 接单率；
- 匹配时长；
- 取消率；
- 活跃乘客、车主和车辆；
- 客诉与申诉。

### 运营主体健康

- 主体状态；
- 活跃车主和车辆；
- 服务质量；
- 付款及时率；
- 开放资金案件；
- 安全和合规限制；
- 账户变更冷静期；
- 退出风险。

### 资金安全

- 已分配金额；
- 平台服务费；
- 运营主体经营份额；
- 车主应付款；
- 待清算和待付款；
- 付款逾期；
- 未知结果；
- 对账差异；
- 未关账账务日；
- 退款和拒付暴露。

### 安全与合规

- 开放重大安全案件；
- 临时冻结数量；
- 恢复访问待复核；
- 严格敏感数据访问异常；
- 权限异常；
- 隐私请求和超时；
- 外部合规阻断。

### 待决事项

只展示真正需要高层决策的事项：

- 运营主体激活、暂停或退出；
- 重大安全事件处置；
- 长期付款逾期；
- 无法闭环的资金差异；
- 生产能力启用评审；
- 法律、财务或合规未决事项。

## 指标口径模板

每个指标必须声明：

```text
指标名称
业务定义
分子
分母
时间范围
时区
数据来源
是否要求关账
数据新鲜度
允许维度
禁止解释
```

## 核心指标

| 指标 | 定义 | 数据来源 | 关账要求 |
| --- | --- | --- | --- |
| 行程完成率 | 完成行程数 ÷ 已进入匹配的有效行程数 | 行程领域 | 否 |
| 接单率 | 被车主接受的有效派单数 ÷ 有效派单数 | 派单领域 | 否 |
| 取消率 | 有效取消行程数 ÷ 已确认行程数 | 行程领域 | 否 |
| 付款及时率 | 截止期限前提交的付款项 ÷ 到期付款项 | 付款批次 | 是 |
| 对账差异率 | 差异绝对金额 ÷ 对账实际金额 | 对账领域 | 是 |
| 关账完成率 | 已关闭账务日 ÷ 应关闭账务日 | 对账领域 | 是 |
| 主体健康度 | 服务、资金、安全和合规指标的规则化结果 | 多领域 | 按组成项 |
| 安全事件率 | 有效安全事件数 ÷ 完成行程数 | 安全与行程 | 否 |

## 数据新鲜度

- 实时运营指标：目标延迟不超过 `5 分钟`；
- 客服和安全案件：目标延迟不超过 `1 分钟`；
- 资金批次：以事务提交结果为准；
- 对账和关账：明确显示批次和账务日状态；
- 高层周报和月报：仅使用已关闭期间数据。

页面必须显示“截至时间”和“是否包含未关账数据”。

## 钻取规则

- 聚合指标可钻取到城市、运营主体、产品和时间维度；
- 钻取到车主、乘客、行程或案件时重新执行原领域权限；
- 高层角色没有严格敏感原文权限时，只显示脱敏摘要；
- 驾驶舱筛选不能扩大角色原有组织和城市范围；
- 导出使用与页面相同的范围和脱敏规则。

## 禁止指标

- 以敏感身份特征进行无批准排名；
- 用单一接单率自动惩罚车主；
- 用投诉数量替代调查结论；
- 把未对账金额表达为可用余额；
- 把处理中或未知付款表达为已到账；
- 用主体规模掩盖安全和资金风险；
- 展示无行动意义的虚荣指标。
