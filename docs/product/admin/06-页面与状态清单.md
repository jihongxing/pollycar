## 页面通用状态

每个页面至少设计：

- 初次加载；
- 正常；
- 空状态；
- 筛选无结果；
- 权限不足；
- 组织范围不匹配；
- 会话过期；
- 临时授权到期；
- 内部沙箱；
- 功能关闭；
- 网络错误；
- 服务降级；
- 并发冲突；
- 数据版本过旧；
- 任务已被他人认领；
- 任务所有权失效；
- 未知结果恢复；
- 数据部分过期；
- 数据源不可用；
- 导出被阻止；
- 严格敏感数据已遮蔽。

## 高风险操作状态

- 缺少结构化理由；
- 缺少工单或目的；
- 复核人与经办人相同；
- 必需检查项未完成；
- 存在未关闭风险；
- 对账门禁未通过；
- 用户或主体可见文案预览；
- 提交中；
- 成功；
- 明确失败；
- 结果未知；
- 幂等查询恢复；
- 权限在确认期间失效；
- 资源在确认期间变更。
