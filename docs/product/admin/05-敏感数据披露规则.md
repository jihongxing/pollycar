# 运营后台敏感数据披露规则

## 原则

- 默认遮蔽；
- 最小必要；
- 按任务目的披露；
- 按字段而非整页授权；
- 访问与决定分别审计；
- 临时披露自动失效；
- 列表和搜索永不返回严格受限原文。

## 披露层级

| 层级 | 示例 | 默认可见角色 | 交互要求 |
| --- | --- | --- | --- |
| 队列摘要 | 申请编号、状态、材料完整性 | 审核员 | 直接可见 |
| 审核字段 | 合成车辆类型、有效期、权属类型 | 任务所有者 | 认领后可见 |
| 遮蔽原文 | 身份、保险、权属材料摘要 | 授权审核员 | 默认遮蔽 |
| 临时原文 | 必要的严格受限材料 | 明确授权角色 | 目的确认、工单、限时 |
| 安全证据 | 伪造、替换、重复绑定证据 | 安全角色 | 安全工单和专项审计 |
| 审计详情 | 谁在何时查看什么 | 审计人员及授权角色 | 只读、字段级过滤 |

## 列表页

允许：

- 合成申请编号；
- 状态；
- 提交时间；
- 材料完整性；
- 风险摘要等级；
- 当前所有者。

禁止：

- 身份原文；
- 联系方式；
- 完整车辆原文；
- 保险文件内容；
- 精确地址或位置；
- 安全证据；
- 审核模型内部特征。

## 详情页

- 默认展示结构化字段和遮蔽摘要。
- 原文区域必须逐项展开。
- 展开前说明访问目的、字段范围和审计。
- 临时访问到期后自动重新遮蔽。
- 切换任务或角色后立即清除已披露内容。
- 截图和复制控制需在实现评审中单独评估，不得承诺绝对防止外部拍摄。

## 原文访问确认

确认面板至少包含：

- 访问字段；
- 当前任务；
- 访问目的；
- 工单或审核编号；
- 允许时长；
- 禁止用途；
- “访问将被审计”提示；
- 取消和确认。

不得使用一个“查看全部”按钮披露整份材料。

## 字段与操作分离

- 能查看字段不代表能修改业务状态。
- 能作审核决定不代表能导出材料。
- 技术运维能处理任务运行，不代表能查看材料。
- 审计人员能查看访问历史，不代表能查看全部被访问原文。

## 合成数据

内部沙箱中的合成材料仍执行同等披露交互，以验证：

- 遮蔽；
- 目的确认；
- 临时授权；
- 超时重新遮蔽；
- 字段级审计；
- 权限失败。

任何检测到的真实材料必须拒绝进入沙箱并记录安全事件。
