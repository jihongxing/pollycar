# 运营控制台完整能力地图

## 能力分层

运营控制台能力分为五层：

1. 组织与权限底座；
2. 日常业务运营；
3. 高风险控制；
4. 经营与决策；
5. 系统运行与审计。

任何模块都必须复用组织范围、权限、任务、审计和数据披露底座，不得各自建立管理员体系。

## 我的工作台

| 能力 | 主要使用者 | 核心产出 |
| --- | --- | --- |
| 我的待办 | 全部内部角色 | 当前需要处理的任务 |
| 即将超时 | 经办与负责人 | SLA 风险 |
| 等待复核 | 经办与复核人 | 职责分离任务 |
| 未知结果 | 运营、财务、技术运维 | 原命令查询和恢复 |
| 重大告警 | 负责人和高层 | 需要关注或决策的风险 |
| 最近操作 | 全部内部角色 | 个人操作轨迹 |
| 临时权限 | 获批人员 | 到期时间和授权目的 |

## 组织与城市

### 运营主体

- 主体名录和状态；
- 入驻案件；
- 企业资质和合同；
- 经营城市；
- 能力档案；
- 商户、结算和付款资料状态；
- 风险等级；
- 限制、暂停和恢复；
- 账户变更冷静期；
- 迁移和退出；
- 主体级审计。

### 城市运营

- 城市启用状态；
- 运力与需求；
- 服务范围；
- 运营主体覆盖；
- 规则版本；
- 重大事件；
- 供应商可用性；
- 城市级待决事项。

## 运力

### 车主

- 准入和资格；
- 主运营关系；
- 车辆绑定；
- 配额；
- 服务质量；
- 安全限制；
- 付款状态摘要；
- 申诉和退出。

### 车辆

- 车辆资料；
- 权属和保险；
- 证照到期；
- 当前车主；
- 历史绑定；
- 审核和复核；
- 风险与限制。

### 主运营关系

- 当前有效关系；
- 生效时间；
- 历史关系；
- 迁移申请；
- 双方确认；
- 迁移前未结事项；
- 历史清算责任快照。

## 行程运营

- 实时行程监控；
- 预约行程；
- 匹配和接单；
- 长时间未匹配；
- 司机迟到和乘客未出现；
- 取消与责任；
- 行程异常恢复；
- 价格和规则快照；
- 运营主体快照；
- 关联客服、安全、退款和资金记录；
- 行程审计时间线。

后台不得通过自由编辑修改行程状态，只能调用明确状态守卫允许的恢复命令。

## 客服与申诉

- 乘客咨询；
- 车主咨询；
- 运营主体咨询；
- 取消争议；
- 费用争议；
- 退款请求；
- 资格申诉；
- 审核申诉；
- 服务投诉；
- 重复案件关联；
- SLA 和升级；
- 用户通知；
- 补偿建议和独立审批。

客服人员只能查看解决当前案件所需的数据，不能默认查看身份证、聊天原文、精确位置和支付机构完整报文。

## 安全与应急

- 安全告警；
- 行程安全案件；
- 人员与车辆风险；
- 临时冻结；
- 证据保全；
- 聊天和位置证据申请；
- 紧急联系人协作；
- 安全申诉；
- 恢复访问；
- 外部机构协作；
- 重大事件复盘。

安全结论与审核、客服和财务结论分别记录，不能相互覆盖。

## 资金运营

### 分配

- 订单可分配金额；
- 平台 `15%`；
- 运营主体 `45%`；
- 车主应付款 `40%`；
- 规则版本；
- 尾差；
- 账本交易引用。

### 清算

- 运营主体清算候选；
- 清算批次；
- 对账门禁；
- 经办和复核；
- 提交、处理中、成功、失败和未知；
- 退款回退和恢复。

### 车主付款

- `T+1` 付款候选；
- 付款批次；
- 车主收款资料状态；
- 冷静期；
- 经办和复核；
- 付款手续费；
- 失败、未知和逾期；
- 提前结算关闭态。

### 对账与关账

- 四方事实；
- 逐笔和汇总对账；
- 差异案件；
- 恢复动作；
- 双人差异解决；
- 账务日关账；
- 清算、付款和关账阻断。

### 账本

- 交易查询；
- 分录查询；
- 科目和复合维度；
- 余额投影；
- 完整冲正关系；
- 全局序列；
- 重建状态；
- 完整性检查。

账本页面全部只读，后台不提供新增分录、修改余额和删除历史的能力。
