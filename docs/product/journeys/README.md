# 用户旅程索引

## 维护规则

每份旅程必须包含：

- 目标与参与角色；
- 进入和退出条件；
- 正常、拒绝、异常和恢复路径；
- 页面和身份上下文；
- 应用命令、领域事件和错误；
- 权限、数据和审计要求；
- 功能关闭与内部沙箱行为；
- 验收标准。
