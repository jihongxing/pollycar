# 0036 真实账号供应商候选与账号策略决策

## 决策状态

- 状态：账号策略已批准，供应商候选已选择
- 批准日期：2026-07-30
- 批准范围：三类供应商测试候选和九项账号策略
- 不包含：采购、合同、安全、隐私与法律、运营与客服、生产启用或真实数据批准

用户已明确要求选择三类供应商、关闭九项剩余账号策略决策，并开始回填六类批准和供应商测试证据。因此本决策可以关闭九项账号策略阻断并建立批准登记入口，但用户的推进授权不冒充任何一类跨职能正式批准。

## 三类供应商选择

### 短信：腾讯云短信 SMS

供应商标识：`tencent-cloud-sms`

选择理由：

- 面向企业用户提供中国大陆验证码短信；
- 支持 API 3.0、SDK、签名和模板管理；
- 支持发送状态查询相关接口、错误码和控制台管理；
- 支持按手机号和时间窗口设置发送频率与用量阈值；
- 与项目已选择的腾讯云车辆材料 OCR 供应商处于同一云生态，可降低首期企业账号、合同和运维分散度。

官方核验入口：

- `https://cloud.tencent.com/product/sms`
- `https://cloud.tencent.com/document/product/382/52076`
- `https://cloud.tencent.com/document/product/382/37809`

选择限制：

- 当前未取得企业认证账号、短信签名、正文模板、套餐、测试凭据、合同或数据处理材料；
- 当前只关闭“供应商已选择”和内部接入规则已形成，不得发送真实短信。

### 成年资格与身份：腾讯云慧眼人脸核身

供应商标识：`tencent-cloud-faceid`

选择理由：

- 官方产品提供实名信息核验、人脸活体和一比一人脸比对能力；
- 支持 App SDK、微信原生 H5、小程序和 API 等接入方式；
- 支持验证记录查询和人工审核等异常闭环能力；
- 官方要求提交企业业务材料申请接入，符合真实身份能力必须单独审批的项目边界；
- 可以覆盖决策 `0010` 和 `0024` 所需的证件、成年判定、活体和本人一致性组合，但具体数据字段和留存方式仍须合同与隐私评审。

官方核验入口：

- `https://cloud.tencent.com/product/faceid`
- `https://cloud.tencent.com/document/product/1007/30999`
- `https://cloud.tencent.com/document/product/1007/56812`
- `https://cloud.tencent.com/document/product/1007/31319`

选择限制：

- 当前未完成企业申请、合同、测试环境、SDK/API 方案确认、数据驻留、删除、准确性、公平性或攻击专项评审；
- 真实身份证件、人脸、活体视频和生物特征继续禁止进入 PollyCar。

### 运营后台身份源：阿里云应用身份服务 IDaaS EIAM

供应商标识：`alibaba-cloud-idaas-eiam`

选择理由：

- EIAM 明确用于企业内部身份管理；
- 官方产品支持 OIDC、SAML、统一身份认证、权限管理和 API 集成；
- 提供二次认证、弱密码检测和人机检测等安全能力；
- 支持云服务和私有化部署形态，可在后续基础设施供应商确定后继续评估；
- 符合决策 `0020` 中运营后台账号必须与 App 用户账号分离、禁止公开注册和依赖企业工作身份的要求。

官方核验入口：

- `https://www.aliyun.com/product/idaas`
- `https://www.aliyun.com/product/idaas/getting-started`
- `https://help.aliyun.com/zh/idaas`

选择限制：

- 当前未取得企业租户、测试应用、Issuer、Client ID、回调域名、托管密钥引用、合同或员工数据处理材料；
- WebAuthn/Passkey、员工离职同步、组映射、会话撤销和审计导出的具体能力必须在测试租户中逐项验收；
- 在测试结果确认前，现有关闭态 OIDC Adapter 保持不变。

## 九项账号策略

### 1. 用户手机号范围

- 首期只支持中国大陆 `+86` 手机号。
- 客户端接受国内十一位手机号输入，服务端规范化为 E.164。
- 不在首期同时引入国际短信、跨区域数据处理和多国家号码规则。

机器值：`mainland_china_plus_86_only`

### 2. 号码回收策略

- 新设备登录、长期未使用、风险信号、供应商号码状态异常或用户争议均可触发手机号重新验证。
- 账户连续 180 天没有成功认证或有效会话后，下次登录必须重新验证手机号。
- 疑似号码回收时不得仅凭短信验证码转移已完成成年资格、车主资格或存在安全案件的账户。
- 争议期间撤销全部旧会话并限制新业务操作，由信任与安全人员人工裁决。

机器值：`risk_and_inactivity_reverification_with_manual_dispute`

### 3. 用户账户恢复

- 持有原手机号时，只允许通过原手机号验证码恢复。
- 无法使用原手机号时，进入人工恢复，不提供仅凭客服问答、设备标识或历史行程即可恢复的路径。
- 人工恢复必须重新完成经批准的身份核验、双人复核和二十四小时冷静期。
- 恢复成功后增加安全版本、撤销全部旧会话，并通知原手机号和已登记安全联系渠道。

机器值：`original_phone_self_service_manual_recovery_with_step_up_and_cooling_off`

### 4. 运营后台账号

- 采用企业托管 OIDC。
- 首选阿里云 IDaaS EIAM。
- 禁止管理员公开注册、共享账号和复用 App 用户账户。
- 工作身份、组织范围和业务能力继续由 PollyCar Server 每次请求重新授权，身份源声明不能直接成为业务权限事实。

机器值：`managed_oidc_alibaba_cloud_idaas_eiam`

### 5. 管理员 MFA

- 正式目标要求抗钓鱼 MFA，优先 WebAuthn/Passkey。
- 如果测试租户暂不支持抗钓鱼方式，可在供应商测试阶段临时使用 TOTP，但必须登记例外、到期时间和升级计划。
- 短信不得作为管理员 MFA。
- MFA 重置需要独立平台批准并撤销全部会话。

机器值：`phishing_resistant_mfa_required_totp_time_limited_exception`

### 6. 会话期限与设备限制

用户账户：

- 访问令牌十五分钟；
- 刷新会话最长三十天，必须轮换；
- 单账户最多三个活动设备会话；
- 刷新令牌重放撤销整个会话族；
- 手机号换绑、账户恢复、身份结果撤销、账户冻结和全部设备退出撤销相关会话；
- 高风险操作要求十五分钟内重新认证。

运营后台：

- 访问令牌十五分钟；
- 空闲超时三十分钟；
- 绝对会话期限八小时；
- 最多三个活动会话；
- 不允许“记住我”；
- 高风险操作要求十五分钟内完成新鲜 MFA；
- 工作身份切换必须创建新会话并使旧访问令牌失效。

机器值：`consumer_15m_access_30d_refresh_3_devices_admin_15m_30m_idle_8h_absolute`

### 7. 成年资格与法定性别

- 批准采用决策 `0010` 的成年资格前置和交易阶段法定性别弱展示方案。
- 手机号认证不能替代成年资格验证。
- 必须同时完成证件核验、出生日期成年判定、活体和本人一致性验证。
- 法定性别不得用于自动匹配、排序、价格、资格、配额、推荐或风控决定。
- 本策略批准不启用真实证件、人脸或生物特征；真实数据仍需隐私、法律、安全和生产批准。

机器值：`decision_0010_adult_eligibility_and_transaction_stage_weak_legal_gender_disclosure`

### 8. 数据保留

- PollyCar 不保存原始身份证图片、原始人脸图片、活体视频、生物特征模板或完整供应商令牌。
- 验证码明文不落库；验证码带密钥摘要在挑战完成或过期后二十四小时内删除。
- 短信和身份供应商请求只保存最小请求摘要、状态、错误分类和审计关联，默认保存九十天。
- 已撤销或过期的普通用户会话记录保存三十天；安全事件关联会话可转入受限安全案件，最长保存一百八十天。
- 设备风险信号默认保存九十天，不保存可直接还原设备内容的数据。
- 手机号密文和检索摘要在账户存续期间保存；账户关闭冷静期结束后进入删除队列，三十天内完成删除，法律保留要求必须另行登记。
- 成年资格只保存最小验证结论、供应商请求摘要、验证时间、策略版本和必要审计；账户关闭后默认一百八十天内删除，争议或法律保留必须单独批准。
- 管理员审计记录按安全审计要求保存一年；包含个人信息的字段继续最小化和分级访问。

机器值：`data_minimization_no_raw_identity_or_biometrics`

### 9. 风控与客服责任

- 安全负责人拥有验证码、设备、会话和攻击检测策略及阈值。
- 信任与安全团队拥有号码争议、人工恢复、账号接管和身份核验异常案件。
- 客服只负责受理、收集最小材料和告知进度，不得单人解锁、换绑手机号、重置管理员 MFA 或恢复高价值账户。
- 工程运维负责供应商故障、回调积压、密钥轮换和会话撤销执行。
- 隐私与法律负责人处理数据访问、删除、身份争议和供应商数据处理问题。
- 高风险人工恢复和管理员 MFA 重置必须双人复核。
- 普通恢复申请一个工作日内响应，高风险争议三个工作日内给出初步结论；无法安全判断时继续限制账户而不是自动放行。

机器值：`security_policy_owner_trust_and_safety_case_owner_support_intake`

## 供应商测试准备规则

三类供应商统一采用以下失败关闭规则：

- 未取得企业账号、合同、数据处理材料和托管测试凭据时不得调用供应商；
- 请求必须带内部幂等键，重复业务请求不得重复产生不可逆供应商操作；
- 回调必须验证 HTTPS、签名、时间窗口、Nonce 或等价重放保护，并绑定原始请求；
- 同步超时或未知结果不得直接重试写操作，优先查询供应商最终状态；
- 结果未知、签名错误、请求不匹配、超时或服务不可用时保持认证未通过；
- 限流至少覆盖账户、手机号、设备、网络来源、管理员账号和租户；
- 普通日志不得记录手机号明文、验证码、身份证件、人脸、活体材料或完整供应商响应。

详细测试用例见 `infrastructure/production-authentication/provider-testing-plan.md`。
