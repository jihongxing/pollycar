# 决策编号：0025 腾讯云车辆材料 OCR 阶段一接入

## 决策状态

- 状态：评审中，已批准默认关闭的代码实现
- 批准范围：驾驶证、行驶证和保险材料的腾讯云 OCR 服务端适配、字段最小化、平台预审和人工复核分流
- 生产启用：否
- 真实材料接收：保持关闭，直到上传隔离、恶意文件检测、凭据管理、隐私授权、合同和删除证明完成
- 最终裁决：始终由 PollyCar 平台执行

## 背景与待解决问题

车主认证已经具备驾驶资格、车辆和保险三类材料任务，但材料仍以合成状态代替真实识别。需要建立可替换、失败关闭且不把供应商结果当作平台决定的服务端 OCR 链路。

腾讯云文字识别提供驾驶证和行驶证结构化接口，但没有可以直接决定保险责任范围和平台准入资格的接口。保险材料只能使用通用 OCR 提取候选文本，责任范围、有效性和车辆一致性仍需平台规则与人工审核。

## 决策目标与非目标

### 目标

- 建立腾讯云 OCR 的服务端适配器和 TC3 请求签名。
- 将供应商结果转换为稳定的平台预审信号。
- 阻止原始证件字段进入业务持久层、日志和用户界面。
- 对超时、未知结果、图片告警和保险材料执行失败关闭。
- 保持车主资格和接单权限由 PollyCar 平台最终裁决。

### 非目标

- 不在本阶段开放真实用户材料上传。
- 不批准真实身份、生物信息或乘客认证供应商。
- 不将 OCR 成功等同于材料真实、保险责任有效或车辆准入通过。
- 不批准生产密钥、生产调用或生产启用。

## 可选方案及权衡

1. App 直接调用腾讯云：实现表面简单，但会暴露云密钥并绕过平台审计，不采用。
2. 服务端把腾讯云结果直接写入车辆审核结论：自动化程度高，但供应商信号会越权成为业务决定，不采用。
3. 服务端调用腾讯云并转换为最小化预审信号，再由平台规则和人工审核裁决：增加一层适配和分流，但能隔离供应商变化并保持平台最终裁决，采用。

## 最终决策

1. 驾驶证使用腾讯云文字识别 `DriverLicenseOCR`。
2. 行驶证使用腾讯云文字识别 `VehicleLicenseOCR`。
3. 保险材料使用 `GeneralAccurateOCR` 提取文本和候选有效期。由于该接口不是保险责任核验接口，保险材料必须进入平台人工复核，不得自动通过。
4. App 不持有腾讯云密钥，也不直接调用腾讯云。所有请求必须由 PollyCar 服务端发起。
5. 服务端使用 `TC3-HMAC-SHA256` 签名，请求域名固定为 `ocr.tencentcloudapi.com`，接口版本固定为 `2018-11-19`。
6. 腾讯云返回只作为 `provider_signal`。供应商成功、字段完整或置信度较高均不得直接授予车主身份、接单资格或其他业务权限。
7. 驾驶证号码、姓名、车辆所有人和 VIN 只允许在单次请求内用于一致性检查；持久结果只能保存不可逆指纹、掩码字段、必要日期、供应商请求编号和平台分流结果。
8. 供应商超时、网络失败、响应缺少请求编号、图片告警、字段缺失和未知结果必须失败关闭，转入人工复核或要求用户重新提交。
9. 腾讯云 API Explorer 会调用实际云服务，不视为隔离沙箱。没有受控测试账号、专用密钥和虚构测试材料时不得进行外部联调。

## 当前实现边界

本阶段实现以下能力：

- 腾讯云 TC3 请求签名；
- 驾驶证、行驶证和保险材料的接口动作映射；
- 文件格式和大小边界；
- 供应商错误、超时和未知结果映射；
- 原始字段最小化与指纹化；
- 驾驶证有效期、车辆关键字段和保险候选日期的平台规则；
- 保险材料和异常材料的人工复核分流；
- 使用模拟 HTTP 响应完成适配器与平台规则测试。

本阶段不实现以下能力：

- App 直接上传真实车辆材料；
- 生产对象存储、隔离区、恶意文件扫描和删除证明；
- 使用真实用户材料调用腾讯云；
- 供应商结果自动批准车辆审核；
- 真实身份、生物信息或乘客认证供应商接入；
- 生产密钥创建、配置或生产启用。

## 产品和业务影响

- 用户完成材料采集后可以获得更快的基础完整性检查，但界面不得展示腾讯云产品名、原始错误码或置信度。
- 驾驶证和行驶证字段完整只代表可以进入平台车辆审核，不代表车主资格已通过。
- 保险材料始终进入人工复核；后续如果引入保险责任核验服务，必须另行批准。
- OCR 不可用时不得自动放行，用户应看到等待、重新提交或人工处理路径。

## 安全、隐私、合规与公平性影响

- 腾讯云密钥只能存在于服务端密钥系统，不进入 App、代码仓库、日志或客户端构建产物。
- 原始文件必须先进入私有隔离区，通过恶意文件检测、真实格式识别和元数据清理后才能调用 OCR。
- 驾驶证号码、姓名、车辆所有人、VIN 和完整保险文本属于高敏感数据，不得进入普通业务日志和长期业务载荷。
- OCR 结果不得用于用户画像、排序、价格、配额或与车辆审核无关的自动决策。
- 自动预审结果必须允许人工复核、重新提交和纠错。

## 验收标准

- TC3 签名、三个 OCR 动作和接口版本具有自动化测试。
- 供应商网络失败、HTTP 失败、错误响应和缺少请求编号时返回未知结果并失败关闭。
- 驾驶证号码、姓名、VIN 和完整保险文本不会出现在平台预审持久结果中。
- 过期驾驶证、缺少关键字段、供应商告警和保险材料进入人工复核。
- OCR 成功不会直接改变车辆审核状态、车主身份或接单权限。
- 未配置供应商凭据和真实材料门禁时，运行时不得调用腾讯云。

## 生产启用门禁

生产启用前必须同时完成：

1. 腾讯云企业账号、文字识别服务开通、合同和数据处理条款。
2. 明确图片处理地域、服务日志、数据保存、模型训练使用、删除和安全事件责任。
3. 单次上传会话、私有隔离存储、恶意文件检测、真实解码、重编码和元数据清理。
4. 专用最小权限子账号、密钥托管、轮换、泄漏检测和调用预算限制。
5. 用户授权、隐私政策、保存期限、删除请求和人工复核流程。
6. 受控测试账号使用虚构材料完成外部联调，不得使用真实个人证件。
7. 回归验证供应商不可用、超时、重复请求、结果未知和预算耗尽时不会授予车主资格。

## 生效与退出条件

### 生效条件

本决策当前只对默认关闭的代码实现生效。外部联调需使用专用测试账号、环境密钥和虚构测试材料，并由安全与隐私负责人确认调用范围。真实用户材料和生产启用必须在全部生产门禁关闭后再次批准。

### 退出条件

出现以下任一情况时关闭腾讯云 OCR 入口并回退到人工关闭态：

- 无法证明材料处理地域、保存期限或删除结果；
- 供应商错误、未知结果或告警被错误转换为自动通过；
- 原始姓名、证件号、VIN 或完整保险文本进入日志、审计或业务持久层；
- 调用成本、误识别率、人工积压或恢复失败超过批准阈值；
- 合同、隐私授权、密钥或安全检测失效。
