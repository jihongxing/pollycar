# 0011 手机号验证码账户与会话体系

## 决策状态

评审中。

允许生产级领域、契约、Server、App 和内部沙箱实现；在短信供应商、安全、隐私、反滥用和真实数据评审完成前，真实短信发送、真实手机号写入和生产认证继续关闭。

## 背景与待解决问题

当前 App 启动后会自动创建合成内部会话，不存在真实账户注册、手机号所有权验证、验证码挑战、设备风险或账户恢复。该模式只能用于内部沙箱，不能作为生产认证。

项目要求注册和登录都只支持“手机号 + 短信验证码”。同时，所有账户在使用任何业务功能前必须完成成年资格验证。需要明确手机号认证、账户创建、成年资格、身份切换、会话和业务准入之间的边界，并覆盖验证码滥用、号码回收、设备丢失、会话泄漏、供应商故障和未知写入结果等异常路径。

## 决策目标与非目标

### 目标

- 注册和登录使用同一个手机号验证码入口；
- 验证码成功后自动判断创建账户或登录现有账户；
- 登录成功不等于获得行程业务权限；
- 与成年资格、乘车人／车主身份切换、会话撤销和全局业务门禁联动；
- 建立生产级频率限制、风险控制、审计、恢复和异常处理；
- 支持短信供应商替换，不让业务代码直接依赖供应商 SDK。

### 非目标

- 不支持密码、邮箱、社交账号、一键登录或第三方联合登录；
- 不允许游客绕过认证使用业务；
- 不以手机号认证替代身份证件和人脸验证；
- 不在本决策中启用真实短信、真实身份数据或生产运营。

## 可选方案及权衡

### 方案一：注册和登录分成两个入口

- 用户需要先判断自己是否有账户；
- 容易造成手机号枚举和账户存在性泄露；
- 页面和异常状态重复；
- 不采用。

### 方案二：统一手机号入口，验证码后登录即注册

- 用户只需完成手机号和验证码两步；
- 服务端在验证码成功后原子判断账户是否存在；
- 对外不暴露手机号是否已注册；
- 便于统一风控、审计和恢复；
- 采用。

### 方案三：手机号验证码直接授予全部业务权限

- 流程短；
- 无法满足全用户成年资格前置要求；
- 手机号所有权不能证明身份和年龄；
- 不采用。

## 最终决策

### 统一入口

App 首屏固定使用：

1. 输入中国大陆手机号；
2. 阅读并同意服务协议、隐私政策和短信用途说明；
3. 请求验证码；
4. 输入六位数字验证码；
5. 服务端验证成功后执行“登录即注册”：
   - 已绑定账户：登录现有账户；
   - 未绑定账户：创建最小账户并登录；
6. 根据账户状态进入下一步：
   - 未完成成年资格：进入成年资格验证；
   - 成年资格评审中：进入状态与恢复页面；
   - 已通过：进入乘车人首页；
   - 账户冻结、注销冷静期或风险锁定：进入对应限制页面。

页面不得提示“该手机号未注册”或“账户已存在”。认证成功前不泄露账户存在性。

### 账户模型

最小账户包含：

- 不可变账户 ID；
- 规范化手机号的加密值和不可逆检索摘要；
- 手机号绑定状态；
- 账户状态；
- 成年资格状态；
- 可用身份和当前身份；
- 创建、更新时间；
- 安全版本号；
- 合成／真实数据来源标记。

账户状态至少包括：

- `pending_adult_eligibility`：手机号已验证，尚未完成成年资格；
- `active`：已完成成年资格且账户可用；
- `restricted`：风险、安全或合规限制；
- `closure_pending`：账户注销冷静期；
- `closed`：账户已关闭；
- `phone_reverification_required`：需要重新验证手机号控制权。

### 验证码挑战

验证码挑战必须绑定：

- 挑战 ID；
- 规范化手机号摘要；
- 用途：`login_or_register`、`phone_reverification`、`account_recovery`；
- 设备和客户端上下文；
- 创建时间、过期时间；
- 最大验证次数；
- 发送次数；
- 状态；
- 短信供应商请求摘要；
- 风险判定和审计关联 ID。

验证码要求：

- 六位数字；
- 有效期五分钟；
- 单次挑战最多验证五次；
- 验证成功后立即消费；
- 新验证码签发后，旧挑战失效；
- 服务端只保存验证码的带密钥摘要，不保存明文；
- App 不得记录验证码、截图验证码或写入分析事件。

### 频率限制与反滥用

首期建议门槛：

- 同一手机号六十秒内最多发送一次；
- 同一手机号一小时最多五次、二十四小时最多十次；
- 同一设备一小时最多十次、二十四小时最多二十次；
- 同一网络来源按风险动态限制，不使用单一 IP 作为永久封禁依据；
- 连续五次验证码错误锁定当前挑战；
- 多手机号轮询、异常设备指纹、自动化行为和供应商异常必须触发更严格限制；
- 风险策略返回通用提示，不泄露具体命中规则。

具体阈值必须通过内部压测、短信成本和误伤率验证后才能生产启用。

### 会话联动

手机号认证成功后签发：

- 短期访问令牌；
- 可轮换刷新令牌；
- 服务端会话记录；
- 设备会话记录。

会话必须包含：

- 账户 ID；
- 会话 ID；
- 设备 ID；
- 签发、最近使用和过期时间；
- 成年资格状态快照；
- 业务准入状态；
- 当前身份；
- 安全版本号；
- 撤销原因和时间。

建议访问令牌有效期十五分钟，刷新会话最长三十天。高风险事件必须增加安全版本并撤销全部旧会话，包括：

- 手机号换绑；
- 账户冻结；
- 身份验证结果撤销；
- 账户注销；
- 用户主动退出全部设备；
- 检测到令牌重放或设备被盗。

### 成年资格与业务准入联动

手机号认证只允许访问：

- 账户基础状态；
- 成年资格验证；
- 验证告知与授权；
- 验证申诉和人工复核；
- 会话、退出和安全设置；
- 必要客服与紧急帮助。

未完成成年资格时必须拒绝：

- 发起或接受行程；
- 车主申请和车辆提交；
- 行程联系；
- 查看交易对方资料；
- 资格、配额和资金操作；
- 除本人验证案件外的业务数据。

成年资格通过后，账户默认获得乘车人身份。车主身份仍需车辆审核、资格、配额、安全和权限条件。

### 手机号生命周期

- 首期不提供用户自助换绑手机号，必须通过人工安全复核；
- 号码停机、回收或运营商重新分配不能自动转移账户；
- 长期未登录、高风险设备或手机号控制权可疑时，要求重新验证并限制敏感操作；
- 手机号解绑或账户关闭后，检索摘要必须进入防重用冷却期；
- 不允许同一手机号同时绑定多个有效账户；
- 不允许通过注销后立即注册绕过安全冻结、资格处罚或审计责任。

## 正常路径

### 新账户

1. 输入手机号；
2. 请求并收到验证码；
3. 验证成功；
4. 原子创建账户、手机号绑定和首个设备会话；
5. 进入成年资格验证；
6. 通过后进入乘车人首页。

### 已有账户

1. 输入手机号；
2. 验证成功；
3. 创建新会话并读取账户状态；
4. 成年资格有效时进入乘车人首页；
5. 恢复用户最近身份偏好时仍重新校验车主身份可用性。

## 异常路径

| 场景 | 用户结果 | 服务端处理 |
| --- | --- | --- |
| 手机号格式错误 | 输入框下方提示格式要求 | 不创建挑战 |
| 请求过于频繁 | 显示稍后重试和剩余等待时间 | 记录限流审计，不调用短信供应商 |
| 短信供应商超时 | 显示“暂时无法发送”，允许安全重试 | 使用请求幂等键查询最终结果，不重复计费发送 |
| 短信供应商返回未知结果 | 提示等待或重新获取 | 标记未知结果，不自动切换供应商重复发送 |
| 验证码错误 | 提示验证码不正确 | 增加挑战错误次数，不泄露账户状态 |
| 验证码过期 | 提示重新获取 | 关闭挑战 |
| 验证码已使用 | 提示重新获取 | 拒绝重放并记录安全审计 |
| 新验证码覆盖旧验证码 | 只接受最新验证码 | 旧挑战标记被替代 |
| 创建账户并发重复 | 用户只得到一个账户 | 手机号摘要唯一约束和事务保证 |
| 认证成功但响应丢失 | App 查询认证结果 | 幂等键返回同一账户和会话，不重复创建 |
| 会话创建失败 | 显示安全重试 | 不返回半完成令牌；账户创建和会话结果可恢复 |
| 账户被冻结 | 不进入业务首页 | 返回通用限制状态和申诉入口 |
| 成年资格未完成 | 进入成年资格验证 | 业务权限固定关闭 |
| 成年资格过期或撤销 | 中断新增业务操作 | 撤销或降权会话，允许查看必要状态与申诉 |
| 设备丢失 | 用户在安全设置退出全部设备 | 增加安全版本并撤销全部会话 |
| 号码疑似被回收 | 要求人工复核 | 不仅凭短信验证码转移高价值账户 |
| App 离线 | 不允许请求或验证验证码 | 保留手机号输入，不缓存验证码 |
| 客户端时间错误 | 使用服务端倒计时 | 不依赖设备时间判定过期 |
| 短信轰炸攻击 | 通用限流提示 | 号码、设备、网络、供应商多层限流和告警 |

## 产品和业务影响

- 登录和注册合并为同一两步流程；
- 首次登录后必须完成成年资格验证，不展示可跳过入口；
- 登录页品牌标题使用“欢迎回来”，按钮根据状态显示“获取验证码”“继续”；
- 不提供密码找回，因为不存在密码；
- 账户恢复、手机号换绑和号码回收属于高风险人工流程；
- 短信成本、送达率和欺诈率成为生产运营指标。

## 安全、隐私、合规与公平性影响

- 手机号属于个人信息，必须加密存储、最小化访问并限制日志输出；
- 检索使用带密钥摘要，不能使用裸 SHA 哈希；
- 验证码、手机号明文和供应商响应不得进入普通日志、分析、崩溃报告或客服截图；
- 短信发送前必须完成用途告知和协议同意；
- 验证码风控不得因地区、设备价格或网络类型直接拒绝特定群体；
- 必须监测送达率、误拦截率、验证码失败率和人工恢复结果差异；
- 短信供应商必须完成数据处理、存储区域、子处理方、安全事件和删除条款评审。

## 验收标准

- 注册和登录只有手机号验证码一种方式；
- 未注册和已注册手机号的认证前响应不可区分；
- 并发认证不会创建重复账户；
- 验证码明文不落库、不进日志；
- 过期、重放、错误次数、限流和未知供应商结果均有稳定错误码；
- 手机号认证成功但成年资格未完成时，所有业务接口仍拒绝；
- 成年资格通过后，会话状态可立即刷新并开放乘车人业务；
- 车主身份切换继续校验车辆、资格、配额、安全和权限；
- 会话过期、撤销、全部设备退出和安全版本变更均有自动化测试；
- 生产短信、真实手机号和生产认证门禁默认关闭；
- 供应商故障、并发、重放、号码回收和账户恢复完成演练。

## 生效与退出条件

### 实现生效条件

- 本决策批准；
- 账户、手机号绑定、验证码挑战、设备和会话机器契约完成；
- PostgreSQL 迁移、Repository、审计和数据生命周期完成；
- App 正常和异常流程通过自动化与人工验收。

### 生产启用条件

- 短信供应商和备用策略批准；
- 隐私影响、安全威胁模型和反滥用阈值批准；
- 真实手机号加密、密钥管理、日志脱敏和删除验证通过；
- 号码回收、人工恢复和客服权限流程演练通过；
- 单独批准真实短信和生产认证功能门禁。

### 退出条件

- 短信送达率、误拦截率或安全事件超过停止阈值；
- 供应商发生未解决的数据或安全事件；
- 无法阻止账户枚举、验证码轰炸、重放或号码回收接管；
- 立即关闭真实短信和新会话签发，保留必要安全访问和人工恢复。
