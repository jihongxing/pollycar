# 0035 阶段三真实账号与认证阻断清单

## 文档目的

本文固定记录阶段三“真实账号与认证”安全空值证据当前产生的 70 项阻断，并作为后续供应商选择、账号策略决策、跨职能批准和验收证据销项的中文事实源。

机器事实源为：

- `infrastructure/production-authentication/readiness-evidence.schema.json`
- `infrastructure/production-authentication/readiness-evidence.example.json`
- `scripts/infra/production-authentication-readiness.mjs`
- `output/production-authentication/readiness.json`

本清单中的“完成”只表示对应证据已真实取得并登记，不得通过占位链接、口头确认或伪造批准消除阻断。所有真实账号、真实手机号、真实短信、真实身份证件、人脸、生物特征、生产认证路由和生产数据库迁移继续保持关闭。

## 销项规则

1. 账号策略只有在 `selectedValue` 明确、决策状态为 `approved` 且登记决策证据后才算完成。
2. “已选择供应商”只关闭 `providerSelected`，不得推导企业账号、合同、测试环境、密钥或数据处理材料已经具备。
3. 内部代码测试不得冒充供应商沙箱联调、真实设备、渗透测试、恢复演练或数据删除验收。
4. 六类批准必须分别签署并登记证据，不得由单一人员代替全部职能。
5. 报告达到 `ready` 只允许进入供应商测试联调，真实数据、生产认证、认证路由和生产迁移仍需独立启用评审。
