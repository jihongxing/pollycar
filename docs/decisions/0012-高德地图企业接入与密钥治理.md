# 0012 高德地图企业接入与密钥治理

## 决策状态

有条件批准（仅内部沙箱实现）。

2026 年 7 月 13 日已完成企业认证、商用授权、隐私影响和 Key 管理方案评审，评审结论为“有条件通过”。允许继续实现生产级适配器、原生模块和内部沙箱验证；在企业认证、技术服务许可、合同与数据处理条款、真实 Key 托管和真实设备验收完成前，不允许启用高德真实能力。

2026 年 7 月 17 日，产品负责人批准按 `AMAP-SANDBOX-20260717` 在内部沙箱继续实现高德地图组件，生产启用继续关闭。批准范围覆盖 Android、iOS 和移动 Web；Android Package 与 iOS Bundle Identifier 均为 `com.yourcompany.pollycar`；首个测试区域为安徽省滁州市；允许前台定位，不允许后台定位。该批准允许完成代码接入、关闭态构建、合成回退和持有真实 Key 后的内部设备验证，不替代企业认证、商业许可、隐私影响评估、密钥托管和生产启用审批。

2026 年 7 月 25 日，受控本地环境已确认存在 Android API Key、移动 Web JS API Key、安全码和内部批准引用，并完成移动 Web 隐私同意后真实底图加载验证；凭据值未写入仓库。当前仍未提供 iOS API Key 和 Server Web Service Key，Android Package 与 iOS Bundle Identifier 仍为占位标识，且缺少 Android 实体设备和 macOS／Xcode 验收环境。本次验证只证明受控内部沙箱的客户端底图接线可用，不构成正式应用标识、企业许可、生产密钥托管、真实设备定位或生产启用批准。

## 背景与待解决问题

PollyCar 计划使用高德提供底图、地点搜索、逆地理编码、路线规划和移动端定位能力。该接入会处理精确位置、行踪轨迹、地点查询和路线信息，并引入企业账户、商业许可、第三方 SDK、Server API 和多类 Key。

需要解决：

- 企业认证账户由谁持有、如何避免员工个人账户控制生产资源；
- 面向公众的商业 App 是否取得适用的技术服务许可和书面授权；
- 高德作为第三方服务接收位置与查询数据时的法律关系、告知同意和数据责任；
- Android、iOS 和 Web 服务 Key 如何申请、绑定、托管、轮换、审计和撤销；
- 如何确保 Expo／React Native 构建不绕过高德官方 SDK 的隐私合规接口；
- 如何在外部条件未完成时继续保持所有真实地图和位置能力关闭。

## 决策目标与非目标

### 目标

- 建立企业认证、商业许可、隐私影响和 Key 管理的生产门槛。
- 明确高德真实能力的账户、合同、数据和密钥责任。
- 允许供应商中立代码继续实现和验证。
- 阻止真实 Key、真实位置或高德 SDK 被单一配置意外开启。

### 非目标

- 本决策不代表已经代表企业完成高德控制台认证。
- 本决策不代表已经购买技术服务许可或签署合同。
- 本决策不批准真实设备定位、后台定位、真实车辆位置流或生产启用。
- 本决策不批准将高德 Web 服务 Key 放入 App。

## 可选方案及权衡

### 方案一：继续只使用合成地图

- 风险最低，不需要企业认证和商业许可。
- 无法完成真实地点、路线和车辆位置体验。
- 适合作为外部条件未完成时的默认回退。

### 方案二：使用个人认证账户和免费配额直接上线

- 接入速度快。
- 企业资源可能由个人账户控制。
- 配额、合同、开票、许可和离职交接风险不可接受。
- 不采用。

### 方案三：企业认证账户、适用技术服务许可和分平台 Key 治理

- 企业主体控制账户、许可、账单和生产资源。
- Android、iOS 与 Server Key 分离，泄漏和轮换影响可控。
- 需要外部认证、商务确认、合同评审和真实设备验证。
- 采用。

## 最终决策

采用方案三，并执行以下规则：

1. 高德生产账户必须由实际运营企业主体申请和持有，绑定企业受控邮箱、手机号和双人可恢复的管理员体系；不得使用员工个人账户作为生产资源所有者。
2. 企业认证所需材料以登录后控制台当期要求为准。仓库不得虚构营业执照、法定代表人或管理员授权材料，也不得保存认证材料原件。
3. PollyCar 属于面向外部用户的商业 App。正式商用前必须取得高德商务或合同渠道对适用技术服务许可、许可档位、应用范围、Key 范围和计费规则的书面确认；未取得书面豁免时，按必须持有有效技术服务许可执行。
4. 技术服务许可、流量包、并发额度和应用 Key 必须登记有效期、绑定应用、购买主体、订单编号、证书编号、负责人和续期日期。
5. 高德 Web 服务 Key 只能由 Server 端受控密钥系统提供；不得进入 App、网页包、源码、测试快照、普通日志、错误响应、分析事件或公开构建产物。
6. 生产环境不得以普通明文环境文件长期保存 Web 服务 Key。应用只能通过 `SecretProvider` 读取受控密钥引用；内部沙箱可以使用未配置状态验证关闭门禁。
7. Android 调试版、Android 发布版、iOS 和 Web 服务分别使用独立 Key。Android Key 必须绑定对应 Package Name、调试 SHA1 或发布 SHA1；iOS Key 必须绑定 Bundle Identifier；不得跨应用复用。
8. Android／iOS SDK Key 虽需随原生应用配置，但仍按受限配置项管理：限制绑定标识、禁止出现在文档和日志、支持独立撤销和轮换，不得与 Server Web 服务 Key 共用。
9. SDK 初始化前必须展示包含高德 SDK 内容的隐私说明并记录用户同意状态，随后调用高德官方隐私展示与同意接口；未完成时不得实例化定位或地图 SDK。
10. 精确位置和行踪轨迹按敏感个人信息处理。采集前必须以显著、清晰方式告知处理者、目的、方式、数据种类、保存期限、权利渠道、第三方接收方或受托方，并取得适用的单独同意。
11. 在合同签署前必须明确高德在各能力中的角色是受托处理者、独立个人信息处理者还是其他关系，并确认处理目的、数据种类、保存与删除、再委托、事件通知、权利响应、审计协助和终止退出。
12. 默认禁止位置数据跨境。若供应商数据流或支持链路可能向境外提供个人信息，必须重新进行跨境评审并完成法定程序。
13. 个人信息保护影响评估记录至少保存三年；评估记录不得包含生产 Key 或不必要的精确位置样本。
14. 必须建立 Key 泄漏检测、访问审计、季度复核、人员离职撤权、紧急吊销和轮换演练。Web Key 泄漏后必须可以在不发布新版 App 的情况下完成切换。
15. 以下门禁继续保持 `false`：`real_map`、`external_map_provider`、`real_device_location`、`background_location`、`real_vehicle_location_stream`、`amap_sdk`、`amap_web_service`。
16. 内部沙箱实现批准编号为 `AMAP-SANDBOX-20260717`。真实 Key 未配置或任一真实门禁关闭时，Android、iOS 和移动 Web 必须继续使用合成地图，不得部分初始化高德 SDK。
17. 首个内部验证区域固定为安徽省滁州市。测试数据不得包含真实用户行踪，前台定位只能在用户主动同意并触发当前地点功能后使用，后台定位保持禁止。

## 产品和业务影响

- 合成地图和供应商中立接口继续可用。
- 真实地图上线需要增加位置告知、授权和权限拒绝恢复体验。
- 未取得许可或 Key 失效时，产品必须退回手动地点、常用地点、最近地点和非实时状态，不得伪造路线或车辆位置。
- 商业预算需包含技术服务许可、超额流量、潜在技术支持和续期成本。
- 企业账户、许可和 Key 必须作为公司资产进入交接和持续运营清单。

## 安全、隐私、合规与公平性影响

- 精确位置和行踪轨迹属于敏感个人信息，只能在特定目的、充分必要和严格保护措施下处理。
- 向第三方提供或委托处理位置数据前，需要完成告知、适用同意和个人信息保护影响评估。
- 位置不得用于推断性别、社交关系、收入、健康、宗教、家庭住址或其他非行程目的。
- 不得将位置用于针对乘车人或车主的差别定价、资格、接单排序或自动处罚。
- 日志、审计和指标只保存服务组、状态、耗时、错误类型、配额和粗粒度区域，不保存精确坐标、完整搜索词或完整路线。
- 高德 SDK、Web 服务和密钥供应链变化需要安全负责人复核。

## 验收标准

- 企业认证账户由企业主体实际控制，并有至少两名受控管理员。
- 取得高德书面商业许可结论；需要许可时，订单、证书和有效期可核验。
- Android 调试、Android 发布、iOS 和 Web 服务 Key 分离并完成绑定验证。
- Web 服务 Key 只存在于批准的 Server 密钥系统，静态扫描和日志检查不发现明文。
- 隐私告知、单独同意、权限拒绝和撤回路径通过产品、法律和安全验收。
- Android／iOS 在 SDK 实例化前调用官方隐私接口，未同意时 SDK 不创建。
- 完成供应商数据处理条款、数据流图、删除与退出、事件响应和跨境结论。
- 完成 Key 泄漏、吊销、轮换、配额耗尽和供应商不可用演练。
- 所有真实门禁关闭时只能使用合成数据，完整预检通过。

## 生效与退出条件

### 生效条件

本决策当前只对“生产级接入准备”生效。真实高德能力必须在全部验收标准完成后，由产品负责人、法律与隐私负责人、安全负责人和工程负责人共同批准独立的生产启用变更。

### 退出条件

- 高德许可条款、价格、SDK 数据行为或隐私接口发生重大变化；
- 更换地图供应商；
- 引入后台定位、轨迹服务、导航 SDK 或跨境数据流；
- 企业主体、应用包名、Bundle Identifier 或签名证书改变；
- 发生 Key 泄漏、供应商数据事件或重大监管要求变化。

发生上述情况必须重新评审。
