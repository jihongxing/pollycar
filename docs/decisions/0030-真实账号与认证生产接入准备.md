# 0030 真实账号与认证生产接入准备

## 状态

评审中。允许继续实现生产认证配置校验、失败关闭适配器、供应商中立端口、测试和审批门禁；禁止发送真实短信、写入真实手机号、接收真实身份证件或人脸、创建真实运营后台账号、挂载生产认证路由或启用业务访问。

## 日期

2026-07-25。

## 背景

PollyCar 已具备合成手机号验证码账户、会话、成年资格验证和运营后台工作身份内核，但这些实现都明确限制为合成数据。共享预生产基础设施设计已经形成，下一步需要把真实账号与认证所需的供应商、密钥、数据、恢复、反滥用和审批边界独立出来，避免通过放宽合成实现进入生产。

真实账号与认证必须拆分为三条独立链路：

1. 用户手机号所有权验证、账户创建和会话；
2. 成年资格、身份证件、活体和人脸一致性核验；
3. 运营后台员工账号、工作身份、MFA 和恢复。

手机号登录不能替代成年资格验证；成年资格验证不能替代运营后台员工认证；任一链路批准不能自动批准其他链路。

## 本阶段已确定

### 用户手机号账户

- 继续采用决策 `0011` 的统一“登录即注册”入口，不向外泄露手机号是否已注册。
- 继续采用六位验证码、五分钟有效期、单挑战最多五次、验证码带密钥摘要、刷新令牌轮换和重放撤销。
- 真实手机号必须使用字段级加密值和不可逆检索摘要，明文不得进入日志、审计、监控或分析。
- 短信发送必须通过 `SmsDelivery` 端口，不允许业务服务直接依赖供应商 SDK。
- 供应商返回未知结果时不得自动重发或自动创建第二条挑战，必须按原请求查询或进入恢复流程。

### 成年资格与实名

- 继续使用独立 `AdultEligibilityProvider` 端口。
- 真实身份证件、人脸、活体材料和生物特征不得进入手机号账户表、普通业务载荷、聊天、通知、通用日志或分析。
- 供应商会话、回调签名、幂等、未知结果查询、人工申诉和删除证明必须在启用前验收。
- 决策 `0010` 仍为评审中，因此真实证件、人脸与法定性别披露继续关闭。

### 运营后台账号

- 真实运营后台账号不得复用 App 手机号账户或内部沙箱管理员身份。
- 推荐优先采用企业托管 OIDC 身份源，并要求抗钓鱼 MFA 或经安全负责人批准的 TOTP；短信不得作为管理员 MFA。
- 工作身份切换必须服务端重新授权并签发新会话，旧会话撤销规则继续生效。
- 若最终决定由 PollyCar 自管密码、TOTP 和恢复码，必须另行批准密码泄漏检查、密钥托管、恢复职责分离和更高运维成本。

## 已完成且不需要外部输入的工作

- 新增独立生产认证准备配置，不复用 `ProductionConfig` 或内部沙箱配置。
- 所有真实认证能力固定为关闭；任何环境变量尝试直接启用都会失败。
- 可校验供应商候选的非本机 HTTPS 地址、托管密钥引用和配置完整性。
- 原始 Access Token、Secret、Private Key 等认证密钥禁止进入环境配置。
- 新增关闭态短信与成年资格供应商适配器，任何调用都返回明确禁用错误。
- 保留现有合成手机号、固定验证码、合成身份和合成管理员内核，不放宽 `synthetic: true`。
- 不创建真实认证数据库迁移，不挂载生产认证 HTTP 路由。

## 需要提供的外部内容

### 短信供应商

- 企业认证完成的供应商账号和合同主体；
- API 文档、境内服务端点、签名与模板审批结果；
- 专用测试凭据的托管密钥引用，不提供明文；
- 发送结果、未知结果查询、回执回调、幂等和限流语义；
- 数据处理条款、手机号处理区域、日志字段、保存与删除证明；
- 单价、预算上限、异常消费告警和停发机制。

### 成年资格与身份供应商

- 供应商选择、企业合同和数据处理协议；
- Android、iOS 和服务端 SDK/API 文档及专用测试环境；
- 身份证件、活体、人脸比对、结果查询和回调签名能力说明；
- 原图、生物特征、结果字段、处理区域、保留期、删除和分包商清单；
- 错误码、未知结果、人工复核、申诉、未成年人和号码/身份不一致处理流程；
- 安全测试、算法准确性、活体攻击防护和公平性评估证据。

### 运营后台身份源

- 是否采用企业托管 OIDC 身份源；
- 身份源租户、Issuer、Client ID、回调域名和专用测试应用；
- Client Secret 或私钥的托管密钥引用；
- MFA 能力、员工离职同步、组或角色映射、会话撤销和审计导出能力；
- 紧急访问、账号恢复、MFA 重置和双人批准责任人。

### 法律、隐私和运营材料

- 手机号、设备、认证日志、身份证件、人脸和生物特征的数据流与分类；
- 隐私政策、短信用途说明、单独同意、第三方处理和生物识别告知文本；
- 保留期限、账户关闭、删除证明、号码回收和历史账号争议处理；
- 客服人工恢复脚本、身份核验材料、职责分离和申诉时限；
- 安全事件、供应商故障、短信轰炸、撞库、会话泄漏和批量账号攻击预案。

## 需要决策的内容

1. 用户手机号范围：首期是否只允许中国大陆 `+86` 手机号。
2. 号码回收策略：多久未验证需要重新验证，旧设备和旧会话如何撤销，争议账号由谁裁决。
3. 账户恢复策略：仅允许原手机号恢复，还是允许人工恢复；人工恢复可接受哪些证据。
4. 运营后台账号策略：采用企业托管 OIDC，还是由 PollyCar 自管邮箱、密码、TOTP 和恢复码。推荐企业托管 OIDC。
5. 管理员 MFA：是否强制 WebAuthn/Passkey，还是允许 TOTP 作为过渡；短信 MFA 必须禁止。
6. 会话策略：用户和管理员访问令牌、刷新令牌、绝对会话期限、设备数量和高风险操作重新认证时限。
7. 成年资格与法定性别：是否最终批准决策 `0010` 的真实证件、人脸和交易阶段弱展示方案。
8. 数据保留：手机号密文、检索摘要、验证码挑战、设备风险、会话、身份证件、人脸和供应商原始结果分别保留多久。
9. 风险与客服：短信频率、设备限制、风险阈值、人工解锁、号码争议和申诉的责任部门与服务时限。
10. 上线范围：先在共享预生产使用供应商测试数据，还是允许受控真实员工数据；默认只允许供应商测试数据和合成数据。

## 启用审批

进入供应商测试环境联调前，至少需要产品与账号策略、安全、隐私与法律、运营与客服、供应商采购与财务、生产决策六类批准。进入真实数据或生产启用前，还必须完成共享预生产基础设施批准、真实设备测试、渗透测试、恢复演练和独立生产启用评审。
