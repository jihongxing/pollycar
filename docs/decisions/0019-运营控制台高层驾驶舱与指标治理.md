# 决策 0019：运营控制台高层驾驶舱与指标治理

## 决策状态

- 状态：`实施前产品决策已完成；尚未批准合成代码实现`
- 设计日期：`2026-07-14`
- 适用环境：仅内部沙箱与合成数据
- 默认门禁：`synthetic_admin_executive_dashboard=false`
- 生产启用：禁止

## 背景

阶段一至阶段四已经形成多组织权限、组织与运力、行程客服安全和资金运营合成内核。项目高层需要理解经营健康、资金安全、重大风险和待决事项，但高层视图若直接拼接数据库表、复制余额或授予通用管理员权限，会产生指标口径漂移、未关账数据误读、跨主体泄露和高层越权经办风险。

本决策只冻结高层驾驶舱的聚合读取、指标治理、钻取、导出和审计边界，不改变任何业务领域状态机，也不授予高层审核、付款、退款、冻结、恢复或配置发布权限。

## 最终决策

### 权威事实与派生视图

- 行程、派单、主体、客服、安全、支付、账本、对账和资金编排继续由原领域拥有；
- 驾驶舱可以维护可重建的指标快照、口径登记、数据新鲜度和导出授权，但不得成为经营或资金权威事实源；
- 所有指标必须保留来源版本、时间范围、时区、截至时间、关账状态和允许维度；
- 未关账金额不得表达为可用余额、已到账收入或可分配资金；
- 周报和月报只允许使用已关闭期间数据。

### 角色

- `executive_sponsor`：平台项目决策人，只读跨领域摘要和待决事项；
- `operator_executive`：运营主体负责人，只读本主体聚合摘要；
- `operations_lead`、`finance_lead`、`safety_lead`、`privacy_compliance`：读取本职责域高层摘要；
- 高层角色不是通用管理员，不继承任何经办、复核或技术恢复权限。

### 组织与钻取

- 平台高层范围来自服务端会话中的城市与运营主体范围；
- 运营主体高层固定为单一主体，不允许上下文切换扩大范围；
- 聚合指标可钻取到城市、运营主体、产品和时间；
- 钻取到行程、人员、案件、付款或账本明细时，必须重新执行原领域授权和字段披露；
- 高层默认最高只读取 `L2` 聚合数据；严格敏感原文、完整收款信息、精确位置和聊天证据禁止从驾驶舱进入。

### 页面

阶段五固定为六页：

1. 高层总览；
2. 经营趋势与城市健康；
3. 运营主体健康；
4. 资金安全；
5. 安全与合规；
6. 待决事项与指标口径。

页面中的经营、资金、安全和合规事实全部只读。待决事项不提供直接批准按钮；唯一允许的写入是追加式高层意见和受控导出治理记录。

高层可以追加记录“高层决策意见”，但该记录不执行任何运营、财务、安全、合规或生产启用命令。意见必须包含结论、理由码、责任角色、截止时间和原待决事项引用；原职责工作台读取意见后，仍按自身权限、状态守卫和职责分离执行实际业务动作。已记录意见不可修改或删除，只能以新意见显式替代。

### 受控导出

- 导出仅包含当前页面允许范围内的聚合脱敏数据；
- 导出申请必须包含目的、时间范围、维度、字段集合和有效期；
- 申请人与批准人必须不同；
- 批准不扩大申请人原有组织范围和字段权限；
- 下载链接短期有效、单次使用并记录审计；
- 严格敏感原文、个人排名、完整付款凭据和未批准身份特征禁止导出。
- 单次导出只能属于经营、资金或安全合规中的一个职责域，阶段五不支持跨职责域合并导出；
- 运营主体负责人申请后，必须由平台 `privacy_compliance` 和对应职责域负责人分别批准；
- 两名批准人都必须与申请人不同，任一拒绝即终止申请。

### 精确资金披露

- `executive_sponsor` 与 `operator_executive` 只读取资金状态、金额区间和趋势，不读取精确聚合金额；
- `finance_lead` 可以在 `L3` 授权、严格审计和已授权组织范围内读取精确聚合金额；
- 精确金额不得通过导出、钻取参数或前端计算间接披露给其他高层角色。

### 禁止解释

- 不得用单一接单率、取消率或投诉数自动处罚个人；
- 不得把处理中、未知或未对账付款表达为已到账；
- 不得以主体规模掩盖安全、资金或合规风险；
- 不得使用敏感身份特征进行排名；
- 不得把驾驶舱快照当作结算、关账、付款或余额依据。

## 后果

收益：

- 高层可以在统一口径下理解经营、资金与风险；
- 多组织范围、未关账标识和字段披露在 Server 端保持一致；
- 经营分析不会形成第二套业务或资金状态。

代价：

- 指标登记、快照新鲜度和钻取授权需要独立机器契约；
- 导出流程需要独立批准和审计；
- 未关闭期间不能生成正式周报或月报。

## 实施门禁

2026 年 7 月 14 日，最终决策人正式批准在默认关闭的 `synthetic_admin_executive_dashboard` 门禁后进入阶段五合成代码实现。允许新增内部沙箱运行时、HTTP 路由、Admin 页面、合成指标适配器和追加式治理记录；门禁默认值不得改变，真实经营、真实财务、真实安全、真实人员数据和生产启用继续禁止。
