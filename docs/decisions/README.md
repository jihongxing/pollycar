# 产品与工程决策索引

本目录记录高风险、难以逆转或存在真实权衡的产品与工程决策。

## 决策状态

| 状态 | 含义 | 是否可进入实现 |
| --- | --- | --- |
| 草案 | 问题与候选方案已记录，尚未完成关键评审 | 否 |
| 评审中 | 已有推荐方案，正在完成业务、安全、法律或工程评审 | 仅可实施评审明确批准的合成、沙箱或关闭态范围；不得启用真实能力 |
| 已批准 | 决策人已批准，验收和生效条件明确 | 是 |
| 已否决 | 明确不采用，并记录原因 | 否 |
| 已替代 | 已由新决策取代，必须链接替代记录 | 按新决策执行 |

## 维护规则

1. 编号一经分配不得复用。
2. 决策标题和正文必须遵守 `AGENTS.md` 的中文文档硬约束。
3. 每份记录必须包含背景、状态、方案权衡、最终决策、影响、验收、生效退出、未决事项、负责人和截止时间。
4. 草案和评审中的“最终决策”必须明确标记为推荐方案或尚未批准，不得伪装成生效规则。
5. 决策状态变化时必须同步更新本索引和 `ROADMAP.md`。
6. 已批准决策改变产品语义、领域规则、数据或交付事实时，必须同步更新对应唯一真相源。
7. 已替代记录不得删除；在文首标记替代记录并保留历史理由。
8. 涉及支付、合规、隐私、安全或公平性的决策，必须记录对应评审负责人。
9. 需要外部或跨职能证据的决策必须关联 `docs/reviews/` 评审清单；阻断项未关闭时不得批准。
