# 真实头像媒体基础设施与内容安全上线计划

## 决策状态

评审中。阶段一供应商产品边界和目标地域已经冻结；合同、隐私、安全、内容治理和生产证据尚未完成。未批准真实头像、真实数据接入或生产启用。

## 背景与待解决问题

内部沙箱已经验证头像选择、裁剪、上传、元数据持久化、替换删除和受控读取闭环，但本地文件存储和技术头校验不能承担真实用户图片。真实头像可能包含人脸、未成年人、第三方人物、位置和设备元数据，也可能携带恶意载荷、超大解码尺寸或违规内容。

生产上线必须将“接收文件”“安全处理”“内容审核”“公开交付”和“删除治理”拆分为可审计、可回滚的独立阶段，不得将上传成功直接等同于公开可见。

## 决策目标与非目标

- 目标：规划真实头像从上传会话到审核发布、替换、删除和安全响应的完整生产链路。
- 目标：明确 App、媒体网关、对象存储、处理队列、审核服务、资料服务和 CDN 的责任边界。
- 目标：为隐私、安全、内容治理和生产负责人提供可逐项签署的启用门禁。
- 非目标：本批不实现新的生产 API、不接入真实对象存储或审核供应商、不迁移真实数据。
- 非目标：头像不得成为资格、价格、排序、匹配、推荐或自动处罚因子。

## 可选方案及权衡

1. 继续由资料接口接收完整 Base64：实现路径最短，但会放大网关内存、日志泄漏和请求重试成本，不推荐用于生产。
2. App 使用长期对象存储凭证上传：吞吐较好，但凭证暴露和越权写入风险不可接受，不采用。
3. 服务端创建单次上传会话，App 使用短时签名地址写入隔离区，再由服务端完成确认、扫描、重编码、审核和发布：组件较多，但权限最小、链路可观测且便于隔离恶意内容，作为推荐方案。

## 最终决策

当前仅批准以下方案进入跨职能评审，不批准生产实现或生产启用：

1. App 通过受认证的头像上传会话接口取得单文件、单用途、短时有效的签名上传地址，不接触对象存储凭证。
2. 原始文件只能写入不可公开读取的隔离区，上传会话绑定账户、对象键、内容长度、允许格式、幂等键和过期时间。
3. 上传确认后进入异步处理队列，依次执行真实格式识别、解码尺寸与像素炸弹防护、恶意文件扫描、图像解码重编码、方向归一化和 EXIF／附加元数据剥离。
4. 只有安全处理成功的标准化衍生图可以进入内容审核；原始文件不能直接进入公开交付区。
5. 内容审核至少覆盖裸露、暴力、仇恨符号、违法内容、明显非头像图片和可能涉及未成年人的高风险场景。供应商低置信度、不可用或策略冲突时进入人工复核，不自动放行。
6. 审核通过后，将固定尺寸与格式的头像衍生图发布至独立交付区，并以版本化媒体标识更新账户资料；缓存键必须随头像版本变化。
7. 上传中、处理中、待审核、需要重新选择、已更新等内部状态必须转换为用户可理解的任务结果，不展示供应商、扫描器、队列或错误码。
8. 替换头像时先发布新版本，再切换资料引用，最后异步删除旧版交付对象和原始隔离对象；失败时保持旧头像可用。
9. 账户删除、撤回头像和隐私请求必须触发资料引用、隔离对象、标准化对象、CDN 缓存、审核副本和备份到期记录的统一删除流程。
10. 所有上传会话、扫描、重编码、审核、发布、读取、替换和删除动作必须具备关联标识、审计事件、最小权限和分环境隔离。
11. 生产启用采用账户白名单、低比例灰度、分平台扩量和一键回退至预设头像的顺序，不允许全量直接开放。
12. 本草案获批时必须更新 `0022` 中“服务端接收完整文件”的阶段性方案，并同步更新公开 API、状态、错误码、授权规则和数据契约。

## 阶段一供应商冻结结果

- 主云候选冻结为阿里云中国站，目标地域为华东 2（上海）。
- 隔离存储冻结为 OSS 标准存储与 SSE-KMS。
- 上传事件冻结为 OSS 事件进入 EventBridge，再由 Function Compute 编排处理。
- 恶意文件扫描候选冻结为 OSS 恶意文件检测，但实时发布所需的单对象 API、通知和时延证据仍是阻断项。
- 内容审核冻结为 OSS 内容安全的通用图片基线检测与头像图片风险检测。
- 解码、像素炸弹防护、方向归一化、重新编码和元数据清理冻结为 Function Compute 内的 PollyCar 自管处理镜像，不直接依赖 OSS URL 图片处理结果。
- 公开交付冻结为 CDN 回源独立私有交付 Bucket；隔离区、处理区和交付区不得共用 Bucket。
- 详细能力边界、官方证据和未决事项见 `docs/reviews/真实头像阶段一供应商冻结记录.md`。

## 分阶段实施计划

### 阶段一：治理与供应商冻结

- 已冻结对象存储、恶意文件扫描候选、图像处理责任、内容审核、CDN 和目标地域。
- 已冻结隔离区、处理区和交付区分离，以及供应商适配器退出边界。
- 待完成头像个人信息影响评估、隐私告知、用途限制、保留期限和删除时限。
- 待完成供应商安全评估、数据处理协议、分包商清单和退出迁移证明。
- 待冻结生产允许格式、最大文件大小、最大像素、衍生尺寸、审核阈值和人工复核处理时限。

### 阶段二：隔离上传与媒体处理

- 新增上传会话、上传确认和处理状态查询契约。
- 建立隔离区对象存储、短时签名、单次使用限制、账户配额和上传速率限制。
- 建立恶意文件扫描、真实解码、像素炸弹防护、重编码和元数据清理流水线。
- 建立失败重试、死信队列、孤儿对象清理和处理时延监控。

### 阶段三：内容审核与人工复核

- 接入自动内容审核并保存策略版本、置信度和审核证据摘要。
- 建立低置信度人工复核队列、访问权限、审计和处理时限。
- 建立用户重新选择、审核超时和供应商不可用时的产品恢复路径。
- 验证头像不会进入资格、价格、排序、匹配或自动处罚逻辑。

### 阶段四：发布交付与删除治理

- 建立标准化头像交付区、版本化 URL、CDN 防盗链和缓存失效策略。
- 建立替换原子性、旧对象删除、账户删除联动和隐私请求删除证明。
- 建立来源审计、异常下载、令牌滥用和批量抓取告警。
- 完成备份保留与到期删除策略，确保删除承诺覆盖恢复副本。

### 阶段五：灰度与生产启用评审

- 完成 Android、iOS 和移动 Web 真机权限、弱网、断点失败、大文件和辅助技术验收。
- 完成容量、峰值、队列积压、供应商超时、对象存储故障和 CDN 回源演练。
- 先向内部白名单开放，再按平台和账户比例扩量；每阶段观察安全事件、失败率和处理时延。
- 任一关键指标越界时停止新上传并回退至预设头像，已通过头像保持只读可用。

## 产品和业务影响

- 用户选择照片后可能经历短暂处理和审核，不再将上传请求成功表达为头像已经公开。
- 审核未通过时只说明如何重新选择，不展示审核模型、策略标签或内部风险分数。
- 旧头像在新头像发布前持续可用，避免资料页和行程页面出现空白头像。
- 头像继续只服务于账户识别和行程相关展示，不形成联系人、社交关系或外貌导向排序。

## 安全、隐私、合规与公平性影响

- 原始头像按高敏感个人资料处理，默认不公开、最短保留、最小权限访问。
- 隔离区、处理区和交付区使用独立密钥、服务身份和生命周期策略。
- 人工复核只显示履职所需内容，禁止下载、批量浏览和用于训练未经批准的模型。
- 审核策略需接受误判、群体差异和未成年人风险评估，并提供人工纠正路径。
- 安全事件响应必须覆盖恶意文件、违规内容误放行、对象泄露、缓存未失效和删除失败。

## 验收标准

- 未完成扫描、重编码和审核的对象无法通过 App、资料接口或 CDN 读取。
- 上传会话过期、重复使用、跨账户使用、超出大小或格式不符时均被拒绝并审计。
- 原始文件中的 EXIF、GPS、设备和附加配置数据不进入公开衍生图。
- 替换失败不影响旧头像；替换成功后旧版本在承诺时限内不可读取。
- 账户删除和隐私删除请求能够生成覆盖全部存储层级的删除证明。
- 自动审核不可用或低置信度时不会自动公开头像。
- 灰度期间具备停止新上传、回退预设头像和保持已通过头像只读的独立开关。
- 生产启用前通过安全测试、隐私评审、容量测试、灾难恢复演练和跨平台实机验收。

## 生效与退出条件

- 当前记录自 2026-07-19 起作为评审输入，不构成生产实现授权。
- 阶段一未决证据关闭前不得实现生产对象存储、真实扫描、真实审核或真实数据接入。
- 阶段二至阶段四必须分别通过安全、隐私和工程验收后，才可进入内部白名单灰度。
- 只有产品、隐私、安全、内容治理和生产负责人共同签署后，才能改变真实数据与生产门禁。
- 供应商退出、重大安全事件或删除承诺无法满足时，必须停止新上传并回退至预设头像。

## 未决事项、负责人和截止时间

- 产品负责人：确认头像审核范围、用户恢复路径和是否提供人工复核申请，阶段一评审前完成。
- 隐私负责人：确认法律依据、告知文本、数据驻留、原始文件保留和删除时限，阶段一评审前完成。
- 安全负责人：完成供应商评估、威胁模型、密钥治理、扫描与安全事件方案，阶段二实现前完成。
- 内容治理负责人：确认审核政策、人工复核流程、未成年人处理和申诉边界，阶段三实现前完成。
- 工程负责人：提交容量模型、状态契约、可观测性、回滚和数据迁移方案，阶段二实现前完成。
- 生产负责人：确认灰度比例、指标阈值、停止条件和发布窗口，阶段五评审前完成。
