## 使用边界

- 日常任务、优先级和下一步只维护在 `../../ROADMAP.md`；不得再建立全局任务总表。
- 普通 UI、应用服务、测试和内部沙箱代码变更不需要新建实施包。
- 只有涉及真实资金、真实数据、生产启用、外部服务、不可逆迁移或跨职能高风险边界的工作，才需要在代码前建立新的实施包。
