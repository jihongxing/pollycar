# 实施包 0002：内部生产级沙箱

## 状态

`已完成`

- 批准日期：`2026-07-11`
- 负责人：`工程负责人、安全负责人`
- 总目标：允许生产级代码实现；禁止生产启用。

## 范围

- 建立 `apps/app` 和 `apps/server` 的生产级模块边界。
- 建立 `packages/contracts` 公开契约。
- 建立 PostgreSQL、身份、任务、审计和可观测性端口。
- 使用内存或本地隔离适配器处理合成数据。
- 将数据生命周期、车辆审核、免费试验和零金额支付契约映射到应用服务。

## 默认关闭

以下配置必须全部为 `false`：

- `production_enabled`
- `real_payment`
- `paid_flex_trial`
- `real_user_invitation`
- `shanghai_pilot`
- `real_data_ingestion`

`internal_sandbox` 可以为 `true`，但仅允许合成数据。

## 明确禁止

- 真实用户注册、邀请、身份资料和车辆原件。
- 真实支付凭据、扣款、退款、发票和分账。
- 上海真实围栏和真实行程。
- 生产密钥、生产数据库、生产监控和公开网络入口。
- 付费弹性资格入口和待支付转换。

## 模块

| 模块 | 允许实现 | 禁止实现 |
| --- | --- | --- |
| App | 合成流程、关闭状态、错误和沙箱标识 | 商店发布、真实登录、真实邀请 |
| Server | HTTP 契约、应用编排、内存适配器 | 真实身份、支付和生产数据库 |
| Contracts | API、功能开关、事件和错误类型 | 供应商对象和内部数据库实体 |
| Tasks | 内存任务、幂等和重放测试 | 生产队列和外部调度 |
| Audit | 合成审计记录和查询 | 敏感原文和真实主体 |
| Observability | 本地日志、内存指标和健康检查 | 生产告警和外部监控凭据 |

## 验收

- 缺少任何开关时按关闭处理。
- 单一开关不能绕过依赖门禁。
- App 不依赖 `packages/domain`。
- Domain 不依赖 Contracts、App 或 Server。
- Server 只通过领域公开 API改变领域状态。
- 沙箱日志和存储不含真实敏感数据。
- 完整预检、类型检查、测试和构建通过。

## 已实现

- 存储仓储和事务端口，以及带乐观并发控制的内存仓储。
- 仅接受合成主体的身份端口和内存身份适配器。
- 具备幂等入队、认领、有限重试、死信和人工重放的内存任务队列。
- 人工重放自动追加合成审计记录。
- 追加式审计端口和内存审计查询。
- 结构化日志、指标、追踪端口和内存适配器。
- 敏感字段日志拒绝规则。
- 存活检查与依赖就绪检查。
- 内部沙箱依赖容器，所有真实能力保持关闭。

## 生产启用边界

不得改为“生产已启用”“公开测试可用”或“上海试点已开放”。
