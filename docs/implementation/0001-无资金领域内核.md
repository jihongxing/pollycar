## 实现范围

### 共享值对象

- `Instant` 与可注入 `Clock`。
- 稳定标识和值相等语义。
- 聚合版本和重复命令标识。
- 结构化领域结果与机器错误码。

### 弹性资格

- 状态和转换命令。
- 守卫、状态版本和非法转换拒绝。
- 免费试验确认、启用、暂停、恢复、撤销、申诉和到期。
- 90 日内最多 60 个启用自然日。
- 付费状态可作为兼容枚举存在，但所有进入付费状态的命令固定返回冻结错误。

### 配额

- 基础和免费弹性策略选择。
- 24 小时、7 日、30 日滚动计数。
- 占用、释放和最终计入。
- 到期或暂停后的基础策略回退。
- 并发版本冲突和重复请求行为。

### 事件与错误

- 通用事件信封。
- 资格和配额事件构建。
- 规范错误码到领域错误的映射。
- 事件载荷不包含真实敏感数据。

## 明确不做

- HTTP API、控制器和 OpenAPI 生成。
- 数据库实体、ORM、迁移和事务实现。
- 真实支付、资格收费、退款和订单支付。
- 用户、车辆和保险资料审核实现。
- 地图、围栏、位置和聊天。
- 日志平台、指标、告警和部署。

## 公开领域 API

实现应提供等价能力，具体函数名可在不改变语义时调整：

- `decideEligibilityTransition(state, command, context)`
- `evaluateQuota(policy, history, now)`
- `occupyQuota(decision, requestId)`
- `releaseOrFinalizeQuota(occupancy, outcome)`
- `countActiveCalendarDays(periods, now, timezone)`
- `buildDomainEvent(fact, metadata)`

公开 API 接收不可变输入并返回结果和待持久化事件，不直接执行 I/O。

## 测试要求

### 正常路径

- 免费确认后进入待启用并通过守卫启用。
- 已启用资格使用 `4/12/18`。
- 基础资格使用 `3/10/15`。
- 合法暂停、恢复、到期和申诉转换。

### 拒绝与边界

- 未知状态回退基础配额。
- 24 小时、7 日和 30 日恰好达到上限及超过上限。
- 90 日窗口恰好 60 日和第 61 日。
- 暂停日不计数，部分启用日计 1 日。
- 到期后高于基础计数时拒绝新接单。
- 所有付费资格命令返回冻结错误。

### 并发与幂等

- 聚合版本不一致拒绝转换。
- 同一请求重复执行返回原结果。
- 配额占用不能部分成功。
- 同一订单并发接受只有一个结果成功。
- 重复释放或最终计入不产生第二个事件。

### 规范一致性

- 代码状态、事件和错误码均存在于对应 YAML。
- YAML 中已用于免费试验的转换在代码中有映射。
- `production_enabled: false` 不得被代码或测试改写。
