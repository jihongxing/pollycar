# 实施包 0003：Expo App 共享外壳与车辆准入

## 状态

`已完成`

## 目标

将已批准的高保真 App 设计参考转化为 React Native 与 Expo 的生产级内部沙箱骨架，覆盖共享外壳、明暗主题、身份切换和车辆准入页面组件。

## 已实现

- Expo 57、React Native 0.86 和 Expo Router 运行时；
- TanStack Query 根级服务端状态容器；
- React Hook Form 车辆资料表单；
- 明亮与暗色独立设计令牌；
- 账户级主题切换；
- 乘客和车主共享主题偏好；
- 单一 App 身份上下文与身份切换面板；
- 内部沙箱标识；
- 乘客工作台；
- 申请车主身份说明；
- 车主资料；
- 车辆资料与合成附件；
- 提交确认；
- 审核中；
- 需要补充材料；
- 审核批准结果；
- 车主工作台关闭态。
- 车辆审核公开契约客户端；
- App 页面由车辆审核契约视图驱动，不再直接伪造审核状态。

## 默认关闭

- 真实支付；
- 付费弹性资格；
- 真实用户邀请；
- 上海试点；
- 真实接单；
- 真实数据写入；
- 真实身份、车辆原件和附件上传。

## 主题规则

- 用户在乘客和车主身份下均可自由切换明暗主题；
- 身份切换不重置主题；
- 主题只改变视觉令牌，不改变业务状态；
- 当前偏好仅在 App 运行内存中保存；
- 未来持久化需要经过数据分类和账户偏好契约评审。

## 验收

- App 严格 TypeScript 类型检查通过；
- 主题令牌测试通过；
- 身份与主题独立性测试通过；
- Expo Web 导出通过；
- 所有真实能力保持默认关闭；
- 完整预检通过。

## 明确不做

- 真实身份登录；
- 真实附件选择；
- 真实网络 API 适配器；
- 应用商店发布；
- 生产主题偏好持久化；
- 运营后台页面实现。
