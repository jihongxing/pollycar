# 共享预生产运行准备

## 当前状态

本手册只定义供应商中立的演练与告警验收标准。外部告警投递、监控供应商、值班责任人和共享环境执行均未批准，任何演练不得接触真实数据。

## SLO 与告警

- API 可用性目标为 `99.9%`；每 30 秒执行一次就绪检查，且必须包含数据库连通性。
- 证书到期不足 30 天、自动续期失败、数据库就绪失败、备份恢复超出 `RTO 60 分钟` 或恢复点超过 `RPO 5 分钟` 时，未来监控系统必须生成告警。
- 日志、指标和追踪不得采集原始请求体、凭据、身份材料、生物特征、精确位置或支付数据。

## 演练顺序

1. 每月在独立恢复目标执行备份恢复，记录恢复点、实际恢复时间、迁移历史、健康检查和访问控制结果。
2. 每季度执行可用区故障切换演练，记录服务可用性、数据一致性、告警触发和回退结果。
3. 每半年从 IaC 重建区域，记录状态摘要、配置差异、告警、失败项与整改负责人。

## 本地证据工具

```powershell
pnpm operational-drill:template
pnpm check:operational-drill
```

模板只适用于本地合成环境，默认输出 `blocked`。只有每个场景均包含开始与完成时间、观察结果、证据引用、责任人，且备份恢复满足迁移历史、健康检查、访问控制、`RPO 5 分钟` 与 `RTO 60 分钟`，证据校验才会通过。

## 失败关闭

- 监控供应商、值班责任人、预算或五类批准缺失时，不得发送外部告警或执行共享环境演练。
- 演练记录缺少恢复点、恢复时间、迁移历史、健康检查或整改责任时，不得标记通过。
