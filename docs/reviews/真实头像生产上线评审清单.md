# 真实头像生产上线评审清单

## 使用说明

本清单用于评审 `0023-真实头像媒体基础设施与内容安全上线计划`。全部阻断项关闭并取得对应负责人签署前，不得启用真实头像、真实数据或生产流量。

## 产品与用户体验

- [ ] 已确认上传、处理中、待审核、需要重新选择和已更新的最终用户表达。
- [ ] 旧头像在新头像发布前保持可用，不出现空白或错误头像。
- [ ] 审核失败提供重新选择路径，不暴露供应商、模型、风险分数或内部错误码。
- [ ] Android、iOS 和移动 Web 的权限请求、弱网恢复和辅助技术体验通过验收。
- [ ] 已确认头像不会扩展为联系人、社交关系或外貌导向推荐能力。

## 隐私与合规

- [ ] 已完成头像个人信息影响评估并确认法律依据。
- [ ] 已冻结用途、数据驻留、原始文件保留、衍生图保留和删除时限。
- [ ] 隐私告知覆盖内容审核、人工复核、供应商处理和用户删除权利。
- [ ] 已完成对象存储、扫描、审核和 CDN 供应商的数据处理协议与分包商审查。
- [ ] 账户删除和隐私请求能够覆盖隔离区、处理区、交付区、缓存、审核副本和备份。

## 安全与内容治理

- [ ] 上传会话具备短时有效、单次使用、账户绑定、大小限制、格式限制和速率限制。
- [ ] 隔离对象无法公开读取，也不能被其他账户引用。
- [ ] 恶意文件扫描、真实解码、像素炸弹防护、重编码和 EXIF 清理均有失败关闭策略。
- [ ] 自动审核低置信度、不可用或策略冲突时进入人工复核，不自动公开。
- [ ] 人工复核权限、审计、防下载和处理时限已经确认。
- [ ] 已完成对象泄露、违规内容误放行、缓存未失效和删除失败的安全响应演练。

## 工程与可靠性

- [ ] 上传会话、处理任务、审核结果、发布版本和删除任务具有独立状态与幂等键。
- [ ] 已建立处理队列重试、死信、孤儿对象清理和供应商熔断。
- [ ] 替换头像满足新版本先发布、资料引用原子切换、旧版本随后删除。
- [ ] 已建立容量模型、峰值压测、队列积压告警和端到端处理时延目标。
- [ ] 已验证对象存储、审核供应商、处理队列和 CDN 故障时的降级与恢复。
- [ ] 日志、指标和追踪不记录图片字节、签名地址、访问令牌或非必要个人信息。

## 灰度与回滚

- [ ] 内部白名单、平台分批、账户比例扩量和观察周期已经确定。
- [ ] 已冻结上传失败率、审核时延、安全事件和删除失败的停止阈值。
- [ ] 具备独立停止新上传、回退预设头像和保持已通过头像只读的开关。
- [ ] 回滚不需要修改账户资格、行程、身份或其他业务状态。
- [ ] 产品、隐私、安全、内容治理、工程和生产负责人均已签署。

## 当前结论

- 状态：未通过。
- 原因：候选供应商和目标地域已经冻结，但隐私影响评估、供应商合同证据、审核阈值、生产基础设施和跨职能签署均未完成。
- 当前允许范围：继续使用内部沙箱合成链路，不得接入真实头像或生产流量。
