# 评审证据索引

本目录保存高风险决策从方案走向正式结论所需的评审证据、签署状态和阻断项。

## 评审状态

| 状态 | 含义 |
| --- | --- |
| 未开始 | 尚未指定材料或开展评审 |
| 准备中 | 正在收集材料、测算或安排评审 |
| 评审中 | 负责人已收到完整材料并正在形成结论 |
| 有条件通过 | 存在必须在生效前完成的限制或整改 |
| 通过 | 负责人已明确签署通过 |
| 不通过 | 存在不可接受风险或否决结论 |
| 已过期 | 依据、法规、价格或方案变化，需要重新评审 |

## 维护规则

1. 评审清单必须关联一份决策记录。
2. “通过”必须有负责人、日期、证据引用和明确结论。
3. 不得用“未回复”“默认同意”或技术实现完成代替批准。
4. 法律、税务、保险、安全、隐私、公平性和财务结论分别签署。
5. 任何阻断项未关闭时，关联决策不得变更为“已批准”。
6. 证据文件存放位置可以是受控外部系统；仓库只记录引用、版本、摘要和访问责任人，不提交敏感原文。
7. 方案、价格、运营地区、法律关系或数据用途发生实质变化时，必须重新评审。
8. 状态变化时同步更新本索引、关联决策和 `ROADMAP.md`。
