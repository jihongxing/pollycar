## 隐私影响评审

### 法律基线

《中华人民共和国个人信息保护法》第二十八条将行踪轨迹列为敏感个人信息；第二十九条要求处理敏感个人信息取得单独同意；第十七条要求告知处理者、目的、方式、种类、保存期限和权利渠道；第二十三条规定向其他个人信息处理者提供个人信息时的告知和单独同意；第五十五条要求处理敏感个人信息、委托处理或向其他处理者提供个人信息前进行个人信息保护影响评估；第五十六条要求评估合法性、必要性、权益影响、安全风险和保护措施，并将评估记录至少保存三年。

官方法律来源：`http://www.npc.gov.cn/npc/c2/c30834/202108/t20210820_313088.html`。

### 数据流

| 数据 | 来源 | 接收方 | 用途 | 最小化与保留 |
| --- | --- | --- | --- | --- |
| 搜索词、城市代码、偏置位置 | App → Server | 高德 Web 服务 | POI 搜索 | 查询缓存 5 分钟；日志不记录完整搜索词和精确偏置坐标 |
| 单点坐标 | App → Server | 高德 Web 服务 | 逆地理编码 | 50 米网格缓存 10 分钟；行程外不长期保存 |
| 起终点坐标 | App → Server | 高德 Web 服务 | 路线规划 | 路线缓存 60 秒；失败不伪造距离和时间 |
| 设备位置 | App 官方 SDK | 高德 SDK／Server | 定位与行程展示 | 未同意不采集；Server 只保存降精度位置 |
| 车辆位置流 | App → Server | 默认不向高德持续上传 | 接驾与履约展示 | 实时缓存一小时；精确位置最长七十二小时；安全证据锁例外 |

风险等级：高。

必须采用目的限制、最小权限、短期保留、精度降级、单独同意和可撤回机制；不得将位置用于社交推荐、性别推断、差别定价、接单排序或自动处罚；默认禁止跨境提供；拒绝位置权限时仍可使用手动地点、常用地点和最近地点。

当前阻断：未取得合同和数据处理条款，无法最终确认双方个人信息处理角色、处理地点、删除退出和事件响应责任；未完成真实用户隐私告知与单独同意文案签署。

## Key 管理评审

| Key | 保存位置 | 绑定 | 是否允许进入 App |
| --- | --- | --- | --- |
| Android 调试 Key | 移动端受控配置 | 调试 Package + 调试 SHA1 | 仅内部 Development Build |
| Android 发布 Key | 移动端受控发布配置 | 生产 Package + 发布 SHA1 | 生产启用批准后 |
| iOS Key | 移动端受控发布配置 | 生产 Bundle Identifier | 生产启用批准后 |
| Web 服务 Key | Server 密钥系统 | 企业应用和服务范围 | 禁止 |

控制要求：

- 开发、测试、演示和生产 Key 分离。
- Web 服务 Key 仅通过 `SecretProvider` 读取。
- CI/CD 只接收密钥引用，不打印密钥值。
- 日志、URL 记录和错误上报必须对 `key` 参数脱敏。
- Server 出站网络只允许批准的高德域名。
- 每季度检查管理员、Key、绑定、调用量和异常来源。
- 人员离职或职责变化后一个工作日内撤权。
- 泄漏时立即停用 Key、切换新 Key、检查日志和调用来源，并形成事件记录。
- Web Key 轮换不得要求发布新版 App。

当前阻断：尚未选定生产密钥系统，尚未创建真实 Key，尚未完成泄漏与轮换实战演练。

## 官方 SDK 接入准备结果

无外部阻断部分已经完成：

- 建立供应商中立原生模块边界，地图隐私初始化输入明确包含“隐私政策已包含高德条款、已展示、已取得同意”三项状态。
- 建立 Expo 配置插件关闭态；默认构建不注入高德 Android 依赖、Manifest Key、iOS Pod 或 Info.plist Key。
- 建立双重启用门禁：必须同时提供外部批准引用和本地平台启用配置；缺少任一条件即阻断构建。
- Android 依赖必须使用固定 Maven 坐标，禁止 `latest.integration`；iOS 预设使用无 IDFA 的地图与搜索 Pod。
- 移动端 Key 只能由受控原生构建环境注入，禁止通过 `EXPO_PUBLIC_*` 进入 JS 包；Server Web Key 继续由 `SecretProvider` 管理。
- 建立 Android 签名证据采集脚本，输出明确标记为内部 Development Build，不能作为生产证据。
- 建立静态与行为检查，覆盖未经批准启用、内部标识启用、批准标识不匹配、公开 Key 环境变量、依赖格式和隐私初始化契约。

尚未执行真实 SDK 验证。获得企业认证、许可、合同、生产标识和真实 Key 后，验证顺序固定为：

1. Android Development Build 验证底图。
2. 验证 POI 搜索。
3. 验证逆地理编码。
4. 验证路线规划。
5. 完成失败、隐私拒绝、Key 错误、配额和离线回退。
6. 在 macOS／Xcode 环境重复 iOS 验证。
7. 单独评审真实设备位置、车辆位置上传和后台定位；前六步通过不自动批准第七步。

3. 尚未签署合同与数据处理条款，隐私角色、处理地点和退出机制未最终确认。

5. 正式 Android Package、发布 SHA1 和 iOS Bundle Identifier 尚未批准；当前内部沙箱标识不得绑定生产 Key。
6. 当前无 macOS／Xcode 环境，iOS 只能完成配置骨架，不能形成真实构建和设备验收证据。
