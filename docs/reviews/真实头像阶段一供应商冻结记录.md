# 真实头像阶段一供应商冻结记录

## 结论

- 冻结日期：2026-07-19。
- 冻结范围：供应商候选、部署地域、产品责任边界、必须补齐的合同和技术证据。
- 主云候选：阿里云中国站，目标地域为华东 2（上海）。
- 当前状态：仅允许进入架构验证、合同评审和安全验证；不得采购长期资源、接入真实头像、写入真实数据或打开生产门禁。
- 退出原则：App、公开账户契约和领域服务不得直接依赖阿里云 SDK；所有供应商能力必须位于可替换适配器之后。

## 冻结后的目标拓扑

1. `avatar-quarantine`：接收短时签名上传，只允许上传服务写入、处理服务读取。
2. `avatar-processed`：保存扫描通过且完成重编码的待审核衍生图，不允许 CDN 回源。
3. `avatar-delivery`：只保存审核通过的版本化头像，不保存原图、扫描失败图或人工复核中图片。
4. EventBridge：接收 OSS 上传事件并投递处理任务。
5. Function Compute：执行真实解码、像素限制、重编码、元数据清理和审核编排。
6. OSS 恶意文件检测：提供恶意文件扫描候选能力。
7. OSS 内容安全：执行通用基线和头像场景审核。
8. CDN：只回源 `avatar-delivery`，启用 URL 鉴权、防盗链、流量告警和版本化缓存。
9. PollyCar 资料服务：持有上传会话、对象版本、审核状态、人工复核结果和发布引用，不保存图片字节。

## 供应商未决证据

- [ ] 阿里云企业合同主体、数据处理协议、分包商清单和上海地域数据驻留承诺。
- [ ] OSS 恶意文件检测针对单对象增量任务的 API、回调、P95／P99 延迟、超时和失败关闭语义。
- [ ] OSS 内容安全头像检测的策略版本管理、置信度字段、结果保存期限和人工复核数据访问范围。
- [ ] Function Compute 受控镜像的基础镜像来源、漏洞扫描、补丁节奏和网络出口限制。
- [ ] SSE-KMS 专属密钥的轮换、禁用、灾难恢复和跨账户访问方案。
- [ ] CDN URL 鉴权、防盗链、缓存删除时限、异常流量封禁和日志保留承诺。
- [ ] 服务终止时对象、日志、审核副本和密钥材料的导出与销毁证明。

## 不采用或暂不冻结

- 不采用公共读 OSS Bucket。
- 不采用 App 持有长期 AccessKey 或可列举对象的 STS 凭证。
- 不采用原图直接通过 CDN 公开。
- 不采用仅凭文件扩展名、Content-Type 或客户端裁剪结果放行。
- 不将 OSS 图片处理视为完整的恶意文件扫描、内容审核或 EXIF 清理证明。
- 暂不冻结外部人工审核外包商；在审核量、处理时限、访问控制和数据处理协议明确前，由内部受限角色承担灰度期人工复核设计验证。

## 阶段一完成条件

- 供应商产品边界和目标地域已经冻结。
- 目标 Bucket、事件、处理、审核和交付责任已经拆分。
- 不足以支持生产的证据已经转化为明确阻断项。
- 未修改公开 API、状态机、权限或生产门禁。
- 只有未决证据全部关闭并完成隐私、安全、内容治理和工程签署后，才能进入阶段二实现评审。
