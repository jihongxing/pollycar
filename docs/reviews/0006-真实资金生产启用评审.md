# 真实资金生产启用评审

## 评审状态

`未开始`

- 关联决策：`docs/decisions/0013-真实资金架构与复式账本.md`
- 前置评审：`docs/reviews/0005-真实资金架构评审.md`
- 当前结论：架构实施已经通过，但真实扣款、退款、分账、绑卡、提现和生产密钥继续禁止。

## 评审目标

本评审只回答一个问题：

> PollyCar 是否已经具备在受控范围内发起第一笔真实资金交易的法律、财务、供应商、安全和工程条件。

## 必须关闭的生产门槛

### 经营与合同

- 最终经营主体已经确定。
- 乘车服务责任、平台服务责任和车主责任已经写入协议。
- 支付机构代收、退款、分账、拒付和争议责任已经写入合同。
- 用户协议和车主协议已经完成法律评审。

### 支付机构

- 微信支付或支付宝商户申请已经通过。
- 行业类目、App、商户号和产品权限与实际业务一致。
- 已取得支付、查询、退款、账单和所需分账或付款权限。
- 已获得正式费率、结算周期、退款限制和服务等级。
- 已在供应商沙箱完成正常和异常验收。

### 服务费与财税

- 服务费与运营系统设计已经批准。
- 平台服务费、车主所得和税费计算规则已经确定。
- 正式会计科目和分录模板已经签署。
- 发票、税务申报、拒付、坏账和追偿规则已经确定。

### 数据保留

- `30 年／10 年／5 年`内部基线已经完成法律、财务、税务和隐私映射。
- 每类数据的起算时间、归档、访问、删除和保留暂停规则已经批准。
- 用户注销与法定财务保留之间的隔离机制已经验收。

### 密钥与权限

- 生产商户号和密钥已经进入 Server 密钥系统。
- 测试和生产环境、商户号、证书和数据库已经隔离。
- 密钥轮换、吊销和泄漏演练已经通过。
- 财务经办和复核已经使用不同账户、不同会话和不同权限。
- 客服、开发和审计权限已经验证。
- 紧急权限启用和回收已经演练。

### 工程与资金安全

- Server 权威报价和金额锁定已经验收。
- 支付、退款、结算、提现和拒付独立状态机已经验收。
- 复式账本借贷平衡、不可变分录和冲正已经验收。
- 回调验签、防重放、金额校验和未知结果查询已经验收。
- 四方对账和必要的银行第五方核对已经验收。
- 重复扣款、重复退款、回调乱序、消息丢失、数据库重启和供应商故障演练已经通过。
- 任意非零金额差异可以阻止结算、提现和关账。
- 真实支付开关只能通过受控发布批准启用。

## 首次启用限制

即使本评审通过，首次启用仍必须：

- 限定内部受控账户和明确交易上限。
- 保持取消费关闭。
- 保持付费弹性资格关闭。
- 不开放平台储值余额。
- 设置每日交易金额和笔数上限。
- 安排财务、安全和工程值守。
- 每日完成正式对账后才允许继续扩大范围。
