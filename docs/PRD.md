# 原始 PRD 迁移说明

原 `PollyCar 产品需求文档（PRD）v0.1` 已于 `2026-07-11` 拆分整合至当前文档体系。本文档不再作为可修改的产品需求唯一真相源，以避免同一规则在多处重复维护。

## 内容归属

| 原 PRD 内容 | 当前唯一真相源 |
| --- | --- |
| 产品摘要、问题、目标、用户、成功标准、指标和最终原则 | `docs/00-product-thesis.md` |
| 产品是什么、不是什么、产品边界、场景标签、内容表达、评价和决策原则 | `docs/01-semantic-alignment.md` |
| 用户资格、运营范围、等单接单、配额、职业化识别、需求控制、定价分账、流程、状态机、安全和 MVP 能力 | `docs/04-domain-model.md` |
| 技术能力、数据域和隐私约束 | `docs/05-data-schema.md`、`docs/07-delivery-and-operations.md` |
| 测试与验收场景 | `docs/06-validation-plan.md` |
| 待决策事项、阶段验收和止损线 | `ROADMAP.md` |
| 上线前置条件 | `docs/07-delivery-and-operations.md` |

## 维护规则

- 后续产品变更直接更新对应唯一真相源，不再向本文档追加完整需求。
- 如需追溯原始 PRD，可从版本控制历史获取；当前目录尚未初始化 Git 时，应在首次建立版本控制前保留外部备份。
- 发现迁移遗漏时，在同一个变更单元内补充对应真相源和本表映射。
