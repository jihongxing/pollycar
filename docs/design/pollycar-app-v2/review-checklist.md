# PollyCar App v2 设计评审门禁

## 产品气质

- [ ] 第一眼能感受到安静、可信、城市和有人情味；
- [ ] 没有后台、模板、豪车会所或技术控制台感；
- [ ] 颜色不是为了装饰，而是有稳定职责；
- [ ] 页面有明确视觉主体；
- [ ] 信息密度适合手机任务。

## 系统一致性

- [ ] R01、D01、S01 使用同一套字体层级；
- [ ] R01、D01、S01 使用同一套间距节奏；
- [ ] 三页的按钮、输入、状态和面板尺寸一致；
- [ ] 同一组件没有页面专属视觉分支；
- [ ] 图标线宽、尺寸和视觉重量一致；
- [ ] 加载、失败、恢复和禁用状态属于同一套系统。

## 交互可用性

- [ ] 每个首屏只有一个主要行动；
- [ ] 主要行动达到最小触摸尺寸；
- [ ] 操作中不会重复提交；
- [ ] 失败后保留上下文和用户输入；
- [ ] 页面返回不会丢失任务；
- [ ] Dialog、焦点和键盘行为可预测；
- [ ] 身份切换经过正常产品流程。

## 语义

- [ ] S01 的 `24 小时联系建议` 单独表达；
- [ ] S01 的 `72 小时会话窗口` 单独表达；
- [ ] D01 的开始接单、正在上线和已上线含义不混淆；
- [ ] 用户界面没有 API 字段、枚举、错误码和内部服务名；
- [ ] 正常路径不持续展示内部沙箱解释。

## 视口

- [ ] R01：390 × 844；
- [ ] R01：430 × 932；
- [ ] D01：390 × 844；
- [ ] D01：430 × 932；
- [ ] S01：390 × 844；
- [ ] S01：430 × 932；
- [ ] 无页面级横向或纵向溢出；
- [ ] 无控制台 JavaScript 错误。
