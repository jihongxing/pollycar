# PollyCar App v2 设计源

本目录是 PollyCar App 新产品气质与视觉系统的候选设计源。

当前 `DESIGN.md` 仍然是现有代码的兼容基线，但不再被视为 App v2 的最终视觉答案。App v2 在完成评审和实现对稿前，不覆盖现有 `DESIGN.md`，也不改变 R01、D01、S01 的既有业务语义和冻结交互。

## 目标

建立一套具有 PollyCar 自身辨识度的移动产品语言：

- 有可信度，但不显得冷硬；
- 有城市感，但不追逐科技炫技；
- 有效率，但不变成订单控制台；
- 有安全边界，但不持续向用户展示内部规则；
- 有情绪温度，但不制造关系承诺或财富等级。

## 文件

- `product-constitution.md`：产品气质、视觉原则和反模式；
- `tokens.json`：Penpot 变量和代码令牌的候选映射；
- `component-inventory.md`：全产品共享组件和使用边界；
- `penpot-boards.md`：Penpot 工作区、页面、画板和首批状态；
- `review-checklist.md`：R01、D01、S01 的设计评审门禁。

## 设计源规则

Penpot 是视觉源，代码令牌是实现源，两者必须通过语义名称对应，不允许按页面临时发明颜色、间距、字号或组件尺寸。

App v2 未经评审通过前：

1. 不替换正式 `DESIGN.md`；
2. 不批量迁移 21 个 App 页面；
3. 不修改 R01、D01、S01 的冻结业务结构；
4. 不用新视觉稿掩盖现有功能缺陷；
5. 不把 Penpot 画板直接当成产品验收结论。
